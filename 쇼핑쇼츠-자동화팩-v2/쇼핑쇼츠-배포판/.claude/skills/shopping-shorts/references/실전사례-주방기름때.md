# 실전 사례 — 주방 기름때 거품 세정제

실제로 만든 기록이다. 숫자와 판단 근거를 그대로 남겨두었으니, 막히는 단계가 있으면
같은 방식으로 접근하면 된다. (결과물: 17.22초 · 1080×1920 · 30fps · 21.5MB)

## 소재 선별 — 링크 10개 중 2편만 썼다

틱톡 링크 10개를 받아서 다음처럼 걸러졌다.

| 결과 | 편수 | 사유 |
|---|---|---|
| ✅ 사용 | 2 | 같은 상품 · 1080×1920 · 워터마크 제거 가능 |
| ⚠️ 미사용 | 1 | 같은 상품이지만 영문 자막이 **화면 중앙**에 통으로 박힘 → 잘라낼 수 없음 |
| ➖ 미사용 | 5 | 다른 상품 (은사 수세미, 스테인리스 크림, 석재 세정제 등) |
| ❌ 실패 | 2 | 포토 슬라이드쇼 — 영상 트랙이 없음 |

**교훈: 링크 10개를 받아도 쓸 건 2~3편이다.** 이게 정상이니 사용자에게 미리 알린다.

### yt-dlp 팁

- 일부 계정은 기본 추출이 실패한다 →
  `--extractor-args "tiktok:api_hostname=api16-normal-c-useast1a.tiktokv.com"`
- 포토 슬라이드쇼는 `-f "b[vcodec!=none]/bv*+ba/bv*"` 로 받으면
  `Requested format is not available` 이 떠서 자동으로 걸러진다.

## 워터마크 실측 — 이 단계가 제일 중요했다

두 소스 **모두** 상하단에 남의 편집물이 박혀 있었다. 프레임을 뽑아 눈으로 확인한 결과:

- 소스 A: 위 `y0~35` 에 `RunningHub AI生成`, 아래 `y1750~` 에 제품 뱃지, `y1855~` 에 영문 고지문 2줄
- 소스 B: 아래 `y1810~` 에 영문 고지문 2줄
  - 11.5초 이후 상단 `Free sponge and towel included!` + 하단 `Click to buy!` → **그 구간 통째로 미사용**
  - 4.5~5.0초에 `Video playback is being accelerated...` 가 화면 중앙에 뜸 → **미사용**

최종 crop:

```
crop=956:1700:62:40,scale=1080:1920:flags=lanczos,fps=30,setsar=1
```

위 40px · 아래 180px를 버리고 9:16을 유지한 뒤 원래 크기로 되돌린다(약 13% 확대).
두 소스 다 원본이 1080×1920이라 이 정도 확대는 화질 손실이 거의 없었다.

## 컷 구성 (5씬 · 씬당 3.833초 = 115프레임)

| 씬 | 구간 | 내용 |
|---|---|---|
| 01 | A 0.00–4.00 | 시커먼 오븐 내부 기름때 + 세정제 분사 **(훅)** |
| 02 | B 17.80–21.80 | 갈색으로 찌든 밥솥에 거품 뿌리기 |
| 03 | B 4.15–6.35 + 2.30–4.10 | 후드 거품이 주르륵 흘러내림 → 가스레인지 |
| 04 | B 25.40–29.40 | 웍 거품이 굳은 기름을 녹여 갈색으로 변함 |
| 05 | B 29.90–31.90 + 32.80–34.70 | 반짝이는 웍 → 제품 3병 뷰티샷 **(CTA)** |

**씬 순서를 한 번 갈아엎었다.** 처음엔 후드·레인지를 4번에 뒀는데,
"후드도, 가스레인지도" 자막이 웍 화면 위에 떠서 어긋났다.
검수 프레임을 보고 3↔4를 바꿔서 해결했다. **대본을 고치는 것보다 이게 훨씬 빠르다.**

```
주방 기름때,

굳은 기름이 거품에 녹아서
이렇게 주르륵 흘러내려요.
후드도, 가스레인지도,
찌든 냄비까지 한 번에.

```

훅(1~2행) → 강점(3~8행) → 반전 한마디(9행) → CTA(10행) 구조다.

## 이전 사례

이 건은 `세탁조 브러시` 건을 복사해서 만들었고, 그 전에 `무타공 전동 커튼` 건으로
전 과정이 처음 검증됐다. 커튼 건의 검증된 컷 순서는:

> 귀찮은 수동 동작 / 제품 등장 (훅) → 무타공 설치 클로즈업 → 리모컨·음성 조작
> → 아침 햇살 침실 → CTA

자막은 짧고 예능식으로. ("누워서 말만 하면 열림")
중국어 검색어: `免打孔电动窗帘`, `自动窗帘机器人`, `智能窗帘`
