     [ 설치.bat ]  더블클릭

 필요한 프로그램을 전부 자동으로 깔아줍니다.
 중간에 파란 창이나 허용 창이 뜨면 "예"를 눌러주세요.

  ※ 처음 실행하면 "창을 닫고 다시 실행하세요" 라는
    안내가 나올 수 있습니다.
    새로 깐 프로그램을 인식시키기 위한 정상 동작입니다.
    창을 닫고 설치.bat 을 한 번 더 더블클릭하세요.

 마지막에 [OK] 목록이 쭉 뜨면 설치 완료입니다.
 전체 5~10분 정도 걸립니다.


────────────────────────────────────────────────────
 2단계 · 실행
────────────────────────────────────────────────────

     [ 시작.bat ]  더블클릭

 클로드코드가 열립니다.
 처음 한 번은 로그인 창이 뜹니다. 본인 클로드 계정으로 로그인하세요.

 그리고 아래처럼 말하면 됩니다.


 ┌──────────────────────────────────────────────┐
 │  쇼핑쇼츠 만들어줘.                          │
 │  상품은 [상품명] 이고                        │
 │  쿠팡 링크는 [파트너스 링크] 야.             │
 │                                              │
 │  소재는 이 틱톡 링크들 써줘:                 │
 │  (링크 붙여넣기)                             │
 └──────────────────────────────────────────────┘


 나머지는 클로드가 스킬 절차대로 진행합니다.
   · 영상 다운로드 → 워터마크 확인 → 컷편집
   · 대본 작성 → AI 음성 나레이션 → 자막 싱크
   · 렌더 → 검수

 중간에 "이 소재 써도 될까요?" 처럼 확인을 물어봅니다.
 완전 무인이 아니라, 품질에 관계된 판단은 같이 보고 갑니다.
 영상 하나에 10~20분 정도 잡으세요.

 완성본은 여기에 나옵니다:
   remotion-project\out\shorts.mp4


════════════════════════════════════════════════════
 자주 나오는 질문
════════════════════════════════════════════════════

Q. 설치.bat이 중간에 멈추거나 에러가 나요
   → 창을 닫고 설치.bat 을 한 번 더 실행해 보세요.
     그래도 안 되면 점검.bat 을 눌러 무엇이 [없음]인지
     확인한 뒤, 시작.bat 으로 클로드코드를 열고
     "없는 것 설치해줘" 라고 하세요.

Q. 렌더에서 cloud operation 어쩌고 하며 죽어요
   → OneDrive 문제입니다. 맨 위 0단계를 보세요.
     폴더를 C:\shorts 로 옮기면 해결됩니다.

Q. 파이썬을 깔아야 하나요?
   → 아니요. 이 버전은 파이썬을 쓰지 않습니다.
     혹시 예전 팩에서 파이썬 때문에 막히셨다면
     이 폴더로 새로 시작하시면 됩니다.

Q. 목소리는 유료인가요?
   → 아니요. 마이크로소프트 무료 음성을 씁니다.
     가입도 결제도 없고 사용량 제한도 없습니다.

Q. 소재 링크가 없어요
   → 클로드에게 "이 상품 소재 어디서 찾지?" 라고 물어보세요.
     틱톡에서 중국어 키워드로 검색하면 소재 품질이 훨씬 좋습니다.
     (예: 무타공 전동 커튼 → 免打孔电动窗帘)

Q. 링크 10개를 줬는데 2개밖에 안 썼어요
   → 정상입니다. 상품이 다르거나, 남의 자막이 화면 중앙에
     박혀 있으면 못 씁니다. 링크는 넉넉히 주시는 게 좋습니다.

Q. 영상 다운로드가 자꾸 실패해요
   → 틱톡이 막을 때가 있습니다. 클로드가 자동으로 재시도하고
     다른 경로로도 시도합니다. 그래도 안 되면 며칠 뒤에
     다시 되는 경우가 많습니다.

Q. 처음부터 렌더가 안 돼요
   → 소재 영상과 나레이션이 아직 없어서 그렇습니다.
     2단계처럼 상품과 링크를 주고 시작하면 순서대로 다 만들어집니다.

Q. 목소리를 바꾸고 싶어요
   → 클로드에게 "남자 목소리로 바꿔줘" 라고 하면 됩니다.

Q. 대본만 내가 직접 쓰고 싶어요
   → [ 대본.txt ] 를 직접 고치고, 클로드에게
     "대본.txt 그대로 써줘" 라고 하세요.
