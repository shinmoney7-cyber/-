# 뷰티 숏츠 모델 레퍼런스 이미지

뷰티 숏츠 제작 시 모델(동일 인물) 레퍼런스로 사용하는 원본 이미지. 모두 941×1672(약 9:16) WebP.

| 파일 | 구도 | 의상/특징 |
|---|---|---|
| model-01.webp | 전신 | 흰 링거 티셔츠 + 검정 미니스커트, 흰 스니커즈, 긴 웨이브 헤어 |
| model-02.webp | 전신 | 라벤더 폴로 니트 + 흰 미니스커트(벨트), 하프업 헤어 |
| model-03.webp | 전신 | 흰 V넥 립 티셔츠 + 검정 미니스커트, 포니테일 |
| model-04.webp | 상반신(앉은 자세) | 하늘색 립 니트 + 흰 팬츠, 로우 번 |
| model-05.webp | 상반신(앉은 자세) | 회색 원숄더 셔링 티셔츠 + 데님, 긴 웨이브 헤어 |
| model-06.webp | 상반신 | 아이보리 트위스트 티셔츠 + 흰 팬츠, 단발 |
| model-07.webp | 상반신 | 회색 셔링 티셔츠, 하프업 헤어 |
| model-08.webp | 상반신(앉은 자세) | 아이보리 레이스 소매 티셔츠 + 베이지 팬츠, 포니테일, 라벤더 네일 |

뷰티(스킨케어·메이크업) 숏츠에는 얼굴이 크게 나오는 상반신 컷(04~08)이 주 레퍼런스로 적합하다.
