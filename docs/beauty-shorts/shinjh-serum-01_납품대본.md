## 2. 공통 촬영·편집 가이드

- **조명**: 자연광 또는 링라이트 정면. 피부 질감이 보이게 과보정(뽀샵·필터) 금지 — 사용 전후 비교 컷은 **보정 강도 동일** 필수.
- **제품 컷**: 라벨 정면이 1초 이상 또렷이 보이게. 손톱·배경 정리.
- **텍스처 컷**: 스포이드/펌프 토출 → 손등 도포 → 펴바름을 매크로(근접)로. 이 컷이 뷰티쇼츠 체류시간을 좌우한다.
- **자막**: 화면 상단 1/3 이내, 1줄 14자 이내, 최대 2줄. 하단 20%는 플랫폼 UI에 가려지므로 비워둘 것.
- **폰트**: 굵은 고딕 (예: Pretendard Bold), 흰 글씨 + 검정 외곽선 또는 반투명 박스.
- **BGM**: 저작권 프리 Lo-fi / 잔잔한 팝, 내레이션 대비 -18dB 수준.
- **첫 프레임**: 검은 화면·로고로 시작 금지. 0초부터 사람 얼굴 또는 텍스처가 보여야 한다.
- **촬영 기본 세팅** (폰 기준)
  - 4K 30fps 세로 촬영, 슬로모션 컷은 120fps 이상. 화면 확대(디지털 줌) 금지 — 2x·3x 렌즈를 쓰거나 카메라를 직접 가까이.
  - 촬영 전 노출·초점 고정(화면 길게 눌러 AE/AF 잠금), 화이트밸런스 5000K 근처로 고정해 장면마다 피부톤이 달라지지 않게.
  - 조명: 창가 자연광(오전 10시~오후 3시)을 키라이트로, 반대편 흰 반사판. 실내는 링라이트 정면 + 소프트박스 45°.
  - 고정 샷은 삼각대, 손 동작 샷은 오버헤드 암. 움직임은 줌이 아니라 카메라를 천천히 미는(푸시인) 방식.
  - 전후 비교 컷(DAY 1 / DAY 7 등)은 삼각대 위치를 바닥 테이프로 표시하고 같은 시간대·노출·화이트밸런스로.
  - 소리(방울·톡톡·문지름)는 휴대폰 마이크 대신 근접 핀마이크로 따로 녹음해 편집 때 맞춤.
- **필수 고지** (영상 첫 화면 좌상단 + 설명란 첫 줄):
  - `유료광고 포함` (또는 `광고`)
  - 설명란: `이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.`

### AI 모델로 제작할 때 (추가 규칙)

- 첫 화면 `유료광고 포함` 옆에 `AI 가상 모델` 표기, 설명란에 "AI로 만든 가상 인물이 출연합니다". 업로드 시 플랫폼 AI 라벨(유튜브 '변경되거나 합성된 콘텐츠', 틱톡 'AI 생성 콘텐츠', 인스타그램 'AI 정보')도 켠다. AI 생성 광고 표시 의무화가 추진 중이므로 납품 시점 기준을 확인한다.
- AI 모델은 실제 사용자가 아니다. "써봤어요·일주일 써보니·인생템" 같은 사용 경험 내레이션 대신 "이렇게 발라요" 시연형으로. C안(1주 기록)은 AI 모델로 만들 수 없다.
- 제형·발색·커버·지속·백탁처럼 제품 성능이 보이는 장면은 실제 제품을 실제로 촬영해 합성한다(스튜디오의 `[실촬영]` 표시). AI가 만든 효과를 실제 효과처럼 쓰면 기만 광고다. 전후 비교도 AI로 만들지 않는다.
- 제품은 실제 제품 사진을 그대로 쓰고, AI가 라벨 글자·용기 모양·색을 바꾸지 않았는지 확대해서 확인한다. 색조는 화면 색과 실물 스와치를 대조한다.
- 손가락 개수·손 모양·눈동자·치아·머리카락 경계가 이상한 프레임은 삭제. 같은 얼굴(Soul ID) 유지, 실존 인물과 닮게 만들지 않기.
- 전문가형 대본도 AI 모델이 의사·약사·피부 전문가를 자처하지 않는다(가운·자격 언급 금지).

### 제품 유형별 대본 5종 (스튜디오 "제품 유형으로 대본 만들기")

제품 유형 8종(기초 스킨케어·기능성·선케어·베이스·립·아이·치크/하이라이터/셰이딩·클렌징)과 길이(15·25·50초)를 고르면 아래 5종 대본(G1~G5)이 한 번에 만들어진다. 모든 대본은 **0~2초 후킹 → 바로 제품 → 제형·테스트 → 화장법 단계별 영상 컷 → 장점 액션 3컷 → 링크** 순서다.

| 유형 | 0~2초 후킹 | 링크 멘트 |
|---|---|---|
| G1 욕망형 | 결과(윤기·발색)를 먼저 보여줘 "나도 저렇게" 욕구 | 이 느낌 원하면 프로필 링크 |
| G2 피해·불편형 | 사용 전 불편한 점(오염·마스크 묻어남·백탁·번짐·얼룩) | 같은 고민이면 프로필 링크 |
| G3 전문가형 | "이 순서만 기억하세요" 정보 선언 (자격 자처 금지) | 순서 저장, 제품은 링크 |
| G4 실험·비교형 | 테스트 결과 장면부터 (실촬영 필수) | 결과 보고 고르기 |
| G5 호기심형 | "이렇게 바르고 있나요?" 질문 | 저장하고 따라 하기 |

- 제품의 장점은 **액션 3개**로 한 컷씩 보여준다(예: 기초 스킨케어 — ① 검지로 볼을 톡 눌렀다 떼며 촉촉하게 차오른 볼 ② 휴지로 눌러도 묻어나지 않는 손등 ③ 고개를 돌리면 움직이는 윤기). 자막은 '촉촉하게 차오른'까지 — '탄력·탱탱'은 기능성 심사·실증 자료가 있을 때만.
- 화장법·바르는 순서는 카드로 소개하지 않고 **단계마다 한 컷씩 영상으로** 넣는다(15초 4컷, 25초 5컷, 50초 최대 7컷). 단계마다 손이 닿는 부위를 화면 중앙에, 같은 위치·조명 유지.
- 구도·카메라: 0프레임부터 피사체 중앙 · 9:16 안전영역(상단 15%, 하단 20%, 오른쪽 15% 비우기) · 눈은 위에서 1/3 선 · 얼굴 정면 눈높이 2x, 제품 로우앵글, 손·제형 탑뷰, 피부결 45° 측면 · 줌 대신 푸시인 · 1.5~3초마다 컷 · 마지막 1.5초 정지로 반복 재생 유도.

## 오픈·도포 대본 공통 연출 (D·E·F안)

> 순서는 항상 **제품 → 직접 열기 → 제형 → 얼굴에 부드럽게 → 윤기 → 링크**. 보는 사람이 '나도 지금 바르고 싶다'고 느끼게 하는 장치는 아래와 같다.

- **첫 1초는 제품**: 병이 화면 중앙에 있는 상태로 시작. 빛이 유리를 스치는 순간(역광·라이트 스윕)을 첫 프레임에 둔다.
- **여는 소리**: 뚜껑 '딸깍', 스포이드 빨아올리는 소리, 방울 '똑'은 핀마이크로 따로 녹음해 크게 살린다. 이 구간은 말을 하지 않는다.
- **손은 절반 속도**: 캡 돌리기·찍기·펴기 모두 평소의 절반 속도. 손톱 정리, 누드톤 네일, 반지·팔찌 빼기.
- **바르는 법을 정확히**: 다섯 군데(이마·양볼·코·턱) 콕콕 → 약지·중지로 안쪽에서 바깥쪽, 아래에서 위로 결 따라 → 눈가는 톡톡 → 손바닥으로 감싸 지그시. 문지르거나 당기지 않는다.
- **표정**: 바를 때 눈을 살짝 감고 편안하게. 핸드프레스에서 숨을 들이쉬고, 손을 뗀 뒤 작게 미소.
- **윤기 컷**: 45° 측광에서 고개를 살짝 돌려 볼의 하이라이트가 움직이게. 보정·필터·뽀샤시 효과 금지(과장 광고 위험).
- **도포·윤기 장면은 생얼로**: 메이크업 얼굴은 쿠션을 올린 뒤(F안 11번~)부터. 화장 효과가 세럼 효과처럼 보이면 안 된다.
- **BGM**: 첫 여는 구간은 무음 + ASMR, 얼굴에 바르기 시작할 때 잔잔한 BGM 진입, 마지막 링크에서 페이드아웃.
- **길이별 쓰임**: 15초는 반복재생(루프)용 — 마지막 컷을 첫 컷(제품)과 비슷한 구도로 끝내 자연스럽게 다시 돌게. 25초는 기본 납품용. 50초는 저장·공유를 노리는 정보형.
