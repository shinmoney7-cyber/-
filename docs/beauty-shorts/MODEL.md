# 뷰티쇼츠 고정 모델

뷰티쇼츠 실사 이미지는 **항상 이 모델로** 만든다. 다른 얼굴로 바꾸지 않는다.

## 얼굴·스타일 기준 (사용자 제공 레퍼런스 5장)

- 20대 한국 여성, 밝은 피부톤, 갈색 눈, 자연스러운 MLBB 립
- 헤어: 밝은 갈색, 로우 포니테일, 얼굴 옆 잔머리
- 의상: 아이보리 반팔 티셔츠 (변형: 아이보리 블라우스)
- 무드: 따뜻한 자연광, 하얀 커튼, 금테 원형 거울, 대리석 화장대, 흰 꽃, 금색 브러시 꽂이
- 레퍼런스 자막 스타일: 상단 세리프체 큰 제목(진갈색 + 골드 그라데이션), 작은 부제, 얇은 골드 선, 우하단 작은 "광고 콘셉트 시안"

## 생성 규칙

1. Higgsfield Soul ID(이 모델로 학습)가 있으면 반드시 `soul_2` + `soul_id`로 생성한다.
2. Soul ID가 없으면 레퍼런스 이미지 1장을 `medias`(role `image`)로 넣고, 위 외형 설명을 프롬프트에 그대로 넣는다.
3. 생성 이미지에는 글자를 넣지 않는다. 자막·유료광고 표기는 `studio.html`에서 합성한다.
4. 레퍼런스 사진은 사용 권한이 있는 이미지만 쓴다. 실존 인물을 닮게 만들지 않는다.
