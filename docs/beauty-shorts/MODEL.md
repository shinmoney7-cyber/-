# 뷰티쇼츠 고정 모델

뷰티쇼츠 실사 이미지는 **항상 이 모델로** 만든다. 다른 얼굴로 바꾸지 않는다.

## Soul ID

- 이름: 뷰티쇼츠 모델
- soul_id: `50572930-5fd2-4ca7-a68a-196bf118aee3` (Higgsfield Soul 2.0, 사용자 업로드 6장으로 학습)
- 생성: `model: soul_2`, `soul_id` 위 값, 9:16, 2k

## 레퍼런스에서 가져오는 것: 모델(인물)만

- 20대 한국 여성의 얼굴, 피부톤, 눈매, 헤어(밝은 갈색, 로우 포니테일, 잔머리)
- 그 외 레퍼런스의 배경(금테 거울·대리석 화장대·흰 꽃), 의상, 소품, 조명 무드, 자막·글자 스타일은 **가져오지 않는다**.
- 배경·의상·소품·연출은 장면 대본(`shinjh-serum-01_납품대본.md`)의 "화면" 설명을 따른다.

## 생성 규칙

1. Higgsfield Soul ID(이 모델로 학습)가 있으면 `soul_2` + `soul_id`로 생성한다.
2. Soul ID가 없으면 레퍼런스 이미지 1장을 `medias`(role `image`)로 넣고, 프롬프트에 "같은 인물의 얼굴만 유지, 배경·의상은 아래 장면대로"를 명시한다.
3. 생성 이미지에는 글자를 넣지 않는다. 자막·유료광고 표기는 `studio.html`에서 합성한다.
4. 레퍼런스 모델은 사용자가 직접 생성한 AI 모델이다 (실존 인물 아님).
