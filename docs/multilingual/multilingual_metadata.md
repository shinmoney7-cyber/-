## HOW TO USE IN YOUTUBE STUDIO

### Adding Language-Specific Metadata
1. Go to **YouTube Studio** → **Videos** → Click the episode
2. Click **"More Options"** → **"Language"** tab (or Advanced Settings)
3. Under **"Translations"**, click **"Add language"**
4. For each language, paste the title and description from this document

### Adding Subtitles
1. In the video editor, go to **"Subtitles"** tab
2. Click **"Add"** → Select language
3. Upload the corresponding SRT file:
   - English → `어머니의_도장_EN.srt`
   - Japanese → `어머니의_도장_JA.srt`
   - Chinese (Simplified) → `어머니의_도장_ZH.srt`
4. YouTube auto-syncs SRT timecodes

### Recommended Publishing Order
1. Upload video (Korean audio)
2. Add Korean subtitles / auto-generate with YouTube's AI
3. Upload EN, JA, ZH SRT files
4. Add EN, JA, ZH translated titles and descriptions
5. Set **default language**: 한국어 (Korean)
