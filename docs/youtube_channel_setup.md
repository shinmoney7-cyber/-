## 9. 수익화 로드맵

| 단계 | 목표 | 예상 기간 | 수익원 |
|---|---|---|---|
| 1단계 | 구독자 100명 | 1~2개월 | — |
| 2단계 | 구독자 1,000명 + 4,000시청시간 | 3~6개월 | YouTube 광고 수익 신청 |
| 3단계 | 구독자 10,000명 | 6~12개월 | 광고 + 슈퍼챗 + 채널멤버십 |
| 4단계 | 구독자 100,000명 | 1~2년 | 광고 + 협찬 + 독립 굿즈 |

### 초기 성장 전략
1. **첫 4주**: 매주 1편 꾸준히 업로드 → 알고리즘 정착
2. **커뮤니티 탭**: 댓글 질문 활용 ("다음 이야기 어떤 걸 원하세요?")
3. **Shorts 활용**: 60분 본편 중 2~3분 클립 → Shorts로 재활용
4. **키워드**: 영상 제목에 `[실화]` `실화드라마` `라디오드라마` 필수 포함
5. **댓글 관리**: 업로드 후 첫 1시간 댓글에 직접 답글 → 알고리즘 신호

## 10. Google 계정 / YouTube 채널 생성 순서

1. **Google 계정 로그인** → youtube.com
2. 우측 상단 프로필 아이콘 → **"채널 만들기"**
3. 채널 이름: `정희의 밤 라디오` 입력
4. **YouTube Studio** (studio.youtube.com) 접속
5. **커스터마이즈** → 브랜딩:
   - 프로필 사진 업로드
   - 배너 이미지 업로드
   - 워터마크 추가 (로고 이미지)
6. **커스터마이즈** → 기본 정보:
   - 설명란 작성
   - 링크 추가 (SNS 등)
7. **설정** → 채널 → 기본 정보:
   - 국가: 대한민국
   - 키워드 입력
8. 첫 영상 업로드 → 공개 설정
