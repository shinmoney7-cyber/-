# EP01 (수요일 · 감정편) — 상세 대본 + 영상 프롬프트

**제목:** 계모에게 버려진 양반집 딸, 우물 속에서 살아 돌아오다
기획 골격은 [EP01_WED.md](EP01_WED.md). 낭독 속도 분당 약 280~300자 기준.

## 사용법

1. 각 장면의 **[이미지]** 프롬프트로 Midjourney/DALL·E에서 컷 생성 (16:9)
2. 같은 이미지를 Kling/Runway/Higgsfield 등 이미지→영상 도구에 넣고 **[모션]** 프롬프트 적용 (5~10초 클립)
3. [해설]/[대사]는 TTS로, [소리]는 CapCut 효과음으로 얹는다
4. 해설이 긴 장면은 같은 이미지에 켄번스(천천히 줌/패닝)로 길이를 채운다

### 공통 스타일 (모든 이미지 프롬프트 끝에 붙이기)

```
Joseon dynasty Korea, 17th century, cinematic film still, dark moody tone,
desaturated earth colors, soft volumetric light, shallow depth of field,
35mm film grain, highly detailed, --ar 16:9 --style raw
```
