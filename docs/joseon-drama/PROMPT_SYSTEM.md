# 조선 전래동화 드라마 — 프롬프트 시스템

롱폼(약 60분) 조선시대 전래동화 스타일 드라마를 **주 2회** 만들기 위한 고정 프롬프트 세트.
순서대로 복사해 쓰면 된다. 예시 결과물은 [EP01_WED.md](EP01_WED.md), 상세 대본·영상 프롬프트는 [EP01_SCRIPT.md](EP01_SCRIPT.md).

> 참고: "100만 조회수", "CTR 10%"는 목표치다. 보장 수치가 아니므로
> 업로드 후 실제 지표(아래 6번)로 확인하고 프롬프트를 수정한다.

---

## 0. 고정 세팅

| 단계 | 도구 | 설정 |
|---|---|---|
| 대본 | ChatGPT / Claude | 아래 1~3번 프롬프트 |
| 음성 | ElevenLabs / Typecast | 해설: 차분한 여성 / 캐릭터: 감정 연기 |
| 이미지 | Midjourney / DALL·E | `Joseon dynasty, cinematic, dark tone, 16:9` |
| 편집 | CapCut / Premiere | 자막 + 효과음 (바람·파도·빗소리) |

장면 반복 단위: **해설 → 장면 → 대사 → 소리 → 감정**

## 1. 메인 생성 프롬프트

```
조선시대를 배경으로 한 전래동화 스타일 드라마를 만들어줘.

[주제]: {예: 계모에게 버려진 양반가 딸 / 누명 쓴 머슴 / 쫓겨난 며느리}
[편 성격]: {수요일=감정편 | 일요일=복수편}
[이전 편 떡밥]: {없으면 '없음'}

다음 구조를 반드시 지켜줘 (시간은 낭독 기준):
- 0~5초: 초강력 훅 (죽음, 버려짐, 배신 등 극단 상황을 첫 문장에)
- 5~30초: 궁금증 유발 (이유는 숨기고 질문을 던진다)
- 30초~3분: 감정 몰입 (주인공의 고통을 구체적으로)
- 3~15분: 갈등 상승 (무시 → 구박 → 노동 → 폭력 → 제거 시도)
- 15~25분: 복선 최소 3개 (각 복선에 [복선①] 식으로 표시)
- 25~35분: 긴장 최고조 (수상한 행동, 비밀 노출 직전)
- 35~50분: 클라이맥스 (폭로 → 충격 → 무너짐)
- 50~60분: 사이다 + 다음 편 떡밥

규칙:
- 문장은 짧게 끊는다. 한 문장에 감정과 상황을 함께.
- 감정 흐름: 슬픔 → 분노 → 긴장 → 충격 → 사이다 (이 순서 고정)
- 중반부는 20~30초마다 새 사건이 하나씩 나온다.
- 각 장면 앞에 [해설] [장면] [대사] [소리] 태그를 붙인다.

출력 형식:
1) 제목 (SEO: 핵심 키워드 앞쪽, 40자 이내) + 대체 제목 2개
2) 2줄 요약
3) 썸네일 문구 3개 (3~4단어)
4) 타임라인별 대본 (위 8구간)
5) 주요 장면별 음성/소리 연출표
6) 쇼츠로 잘라낼 구간 3개 (시작~끝 시간, 첫 문장)
```

## 2. 썸네일 프롬프트 (1번 뒤에 이어서)

```
이 편의 썸네일을 클릭률 최대화 목표로 설계해줘.

조건:
- 감정 극대화 (눈물, 충격, 공포 중 하나에 집중)
- 텍스트 3~4단어, 정보가 아닌 감정/궁금증
- 영상 내용과 실제로 일치할 것 (낚시 금지 — 이탈률이 올라간다)

출력:
- 썸네일 문구 3개
- 각 문구별 이미지 구도 (인물 위치, 배경, 조명, 색)
- 표정/감정 디테일 (눈, 입, 손)
- 이미지 생성 프롬프트 (영문, Midjourney용)
```

## 3. 주 2회 연결 프롬프트

```
1주 2편 구조로 기획해줘.

- 수요일 편: 감정 중심 (슬픔, 공감). 끝은 '억울함이 쌓인 채' 멈춘다.
- 일요일 편: 복수 중심 (반전, 사이다). 수요일 편의 복선을 모두 회수한다.

두 편 모두 1번 구조를 따르고,
수요일 편 마지막 1분에 일요일 편 떡밥을 3개 심어줘.
각 떡밥이 일요일 편 몇 분대에 회수되는지 표로 정리해줘.
```

## 4. 주간 운영 루틴

| 요일 | 할 일 |
|---|---|
| 월 | 1·3번 프롬프트로 이번 주 2편 기획 |
| 화 | 수요일 편 음성·이미지·편집 |
| 수 | 수요일 편 업로드 + 쇼츠 1개 |
| 목·금 | 일요일 편 제작, 쇼츠 2개 업로드 (수요일 편 유입) |
| 일 | 일요일 편 업로드 + 쇼츠 |
| 토/월 | 지표 확인 → 6번 체크리스트로 다음 주 수정 |

롱폼 1편 → 쇼츠 3개 = **콘텐츠 4개**. 쇼츠 설명란/고정댓글에 롱폼 링크.

## 5. 업로드 전 체크리스트

- [ ] 첫 3초에 충격 문장이 있다 (인사·채널 소개 없음)
- [ ] 15분 안에 갈등 5단계가 모두 나온다
- [ ] 복선 3개 이상, 모두 회수(또는 다음 편 예고)된다
- [ ] 마지막 10분에 사이다가 있다
- [ ] 썸네일 문구가 영상 내용과 일치한다
- [ ] AI 생성 이미지/음성 사용 시 YouTube "변경되거나 합성된 콘텐츠" 표시 확인
- [ ] 효과음·BGM 라이선스 확인

## 6. 조회수 테스트 (업로드 후 48시간)

YouTube Studio → 분석에서 확인:

| 지표 | 보는 곳 | 기준 미달 시 수정할 곳 |
|---|---|---|
| 노출 클릭률(CTR) | 도달범위 | 2번 썸네일/제목 교체 (A/B 테스트 기능 사용) |
| 30초 시청 유지율 | 참여도 → 유지율 그래프 | 1번의 0~30초 훅 |
| 중반 급락 구간 | 유지율 그래프 | 해당 시간대에 사건 추가 |
| 평균 시청 지속시간 | 참여도 | 3~15분 갈등 밀도 |
| 일요일 편 유입 중 수요일 편 비율 | 트래픽 소스 → 최종 화면/추천 | 3번 떡밥 강도 |

결과를 아래처럼 기록하면 다음 기획 때 프롬프트에 붙여 넣을 수 있다:

```
[지난 편 결과] CTR {x}% / 30초 유지율 {y}% / 급락 구간 {mm:ss}
→ 이번 편은 {수정 사항}을 반영해줘.
```
