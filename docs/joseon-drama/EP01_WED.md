# EP01 (수요일 · 감정편) — 기획 패키지 예시

[PROMPT_SYSTEM.md](PROMPT_SYSTEM.md) 1~3번 프롬프트를 적용한 결과 예시.
전체 60분 대본은 이 골격을 1번 프롬프트에 [주제]로 넣어 생성한다.

## 1. 제목

- **메인:** 계모에게 버려진 양반집 딸, 우물 속에서 살아 돌아오다 | 조선 전래동화 드라마
- 대체 1: 죽은 줄 알았던 아씨가 돌아왔다 | 조선시대 감동 사연
- 대체 2: 우물에 던져진 딸, 그날 밤 아버지가 본 것 | 전래동화 몰아보기

## 2. 2줄 요약

어머니를 잃은 열두 살 연이는 새로 들어온 계모의 손에 우물 속으로 버려진다.
모두가 죽었다고 믿은 그날 밤, 우물 밑에서 누군가 연이의 이름을 불렀다.

## 3. 썸네일

| 문구 | 구도 | 표정/디테일 |
|---|---|---|
| **"버려진 이유"** | 왼쪽 2/3 연이 클로즈업, 오른쪽 어두운 우물 입구 | 젖은 머리, 눈물 고인 눈, 입술 꽉 다묾 |
| **"죽지 않았다"** | 우물 안에서 위를 올려다보는 앵글, 위에 계모 실루엣 | 연이 눈동자에 달빛 반사, 손끝에 피 |
| **"계모의 비밀"** | 계모 얼굴 반만 촛불 조명, 뒤로 연이 그림자 | 계모 입꼬리만 웃고 눈은 차가움 |

Midjourney: `Joseon dynasty, 12-year-old girl in white hanbok, soaked hair, tears, looking up from inside a stone well, moonlight, cinematic, dark tone, high contrast --ar 16:9`

## 4. 타임라인 골격

| 구간 | 내용 | 감정 |
|---|---|---|
| 0~5초 | [해설] "그날 밤. 열두 살 연이는 우물 속으로 떨어졌다. 등을 민 건… 어머니였다." | 충격 훅 |
| 5~30초 | 왜 '어머니'인가? 연이는 왜 비명을 지르지 않았나? (답은 숨김) | 궁금증 |
| 30초~3분 | 생모의 죽음, 상여 뒤를 따르는 연이, 아버지는 한양에 있어 부재 | 슬픔 |
| 3~15분 | 계모 윤씨 입성 → 밥상 치움(무시) → 비단옷 빼앗김(구박) → 새벽 물긷기(노동) → 회초리(폭력) → 우물가 사건(제거 시도) | 분노 |
| 15~25분 | [복선①] 생모가 남긴 은가락지 / [복선②] 우물 벽의 오래된 손자국 / [복선③] 계모 친정에서 온 수상한 편지 | 의문 |
| 25~35분 | 늙은 머슴 돌쇠가 밤마다 우물가에 가는 이유 / 계모가 편지를 태우다 들킬 뻔함 | 긴장 |
| 35~50분 | 아버지 귀향 → 계모 "연이는 병으로 죽었다" → 돌쇠가 은가락지를 내밂 → 아버지 무너짐 | 충격 |
| 50~60분 | 우물 아래 숨겨진 옛 수로에서 연이 생존 확인 (작은 사이다) → 일요일 떡밥 | 사이다 + 떡밥 |

## 5. 음성/소리 연출

| 장면 | 소리 | 음성 |
|---|---|---|
| 오프닝 우물 | 물 떨어지는 메아리, 바람 | 해설: 낮고 느리게 |
| 상여 | 요령 소리, 곡소리 원경 | 연이: 울음 참는 떨림 |
| 회초리 | 짧은 타격음 + 정적 1초 | 계모: 차갑고 낮게 |
| 편지 태우기 | 촛불·종이 타는 소리 | 무음 → 발소리로 긴장 |
| 아버지 귀향 | 말발굽, 대문 삐걱 | 아버지: 처음엔 밝게, 이후 무너짐 |
| 엔딩 | 수로 물소리 + 심장박동 | 연이: "아버지… 저 여기 있어요." |

## 6. 쇼츠 추출 3개

1. **0:00~0:50** — "등을 민 건 어머니였다" 훅 그대로
2. **12:00~12:55** — 회초리 장면, 연이가 은가락지를 숨기는 순간
3. **47:30~48:30** — 돌쇠가 은가락지를 내미는 폭로 장면
