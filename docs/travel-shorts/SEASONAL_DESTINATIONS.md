# 청귤트립 계절·월별 여행지 데이터베이스

> 2026-11-21 웹 자료 취합. 축제 날짜는 **확정된 것만 "확정"**으로 적고, 나머지는 2026년 일정이나 평년 기준입니다.
> 영상에 넣기 전에 공식 홈페이지로 다시 확인하세요. 표시: ✅ 확정 / 📅 2026년 기준(2027년 미발표) / ☁️ 평년 시기

## 0. 핵심 원칙
1. **업로드는 여행 시기 4~8주 전.** 예약은 출발 1~2개월 전에 합니다. 축제·꽃은 2~3주 전에 "곧 절정" 영상이 가장 잘 됩니다.
2. **한 달에 세 축을 섞습니다.** 국내 기차/자동차(조회수·쿠팡) + 숙소(큰 수익) + 해외(eSIM·보험·투어).
3. **타깃 두 갈래.** 5060·가족(차분, 편의·건강·가성비) / 연인·커플(감성, 야경·스파·기념일).
4. **해외는 한국인 수요가 확인된 곳 우선.** 2025~2026 예약 자료 기준 일본·베트남이 압도적이고 태국·대만·인도네시아가 뒤를 잇습니다. 연말연시 가족여행도 일본·베트남이 강세(아고다, 2026-10-30).
