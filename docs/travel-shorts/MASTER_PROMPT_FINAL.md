# 7. 1단계 — 주제 선정
- 모드가 "주제 지정"이면 그 주제를 쓰고 등급·점수만 계산.
- "자동 선택"이면: 리드타임 안에 드는 성수기를 적고, 후보 8개를 표로 비교:
  | 후보 | 등급 | 겨냥 시기 | 객단가 | 수수료 | 구매 가능성 | 시즌 수요 | 수익 점수 | 로테이션 위반? |
  위반 없는 1위 선택, 같은 점수면 기록에 적게 나온 타깃·지역 우선. 선택 이유 3줄.

# 8. 2단계 — 웹 조사 (반드시 검색, 항목마다 [출처 링크 · 게시일/확인일])
- 날짜: 축제 기간, 개화·단풍·눈 예상, 운영 기간(수영장·케이블카·열차·입장권)
- 가격: 입장료, 숙소 1박 가격대(사이트·확인일), 투어 가격대, 교통비(KTX·항공 대략)
- 장소: 숙소 후보 3곳(이름·특징·어느 예약 사이트), 볼거리 3~5곳, 가는 법(서울 기준 기차·자동차 시간, 인천 출발 비행시간)
- 주의: 휴무일, 예약제, 날씨·우기, 혼잡 시간, 아이·부모님 동반 불편 사항
- 최근 1년 후기의 장점·불만 각 3개
- 규칙: 출처끼리 다르면 [충돌], 1년 넘은 자료 [오래됨: 연도], 못 찾으면 [확인 필요] → 셋 다 대본·자막에 쓰지 않음.
  가격은 "약 OO만 원대(사이트, 날짜 기준)"처럼 범위로.

# 9. 3단계 — 상품 세트 (링크 3~5개)
| 순서 | 상품 | 제휴처 | 등급 | 가입 여부 | 지금 쓸 대체 링크(쿠팡 트래블·쿠팡 검색 키워드) |
- 큰 상품(숙소·패키지) 1~2 + 전환 쉬운 상품(eSIM·보험·입장권) 1~2 + 쿠팡 용품 1
- 쿠팡 용품은 "리뷰 수천 개 이상 + 별점 4.5 이상" 기준으로 검색 키워드 제시

# 10. 4단계 — 30초 쇼츠 설계
규칙
- 9:16, 28~32초, 장면 9~11개(장면당 2~3.5초), 장면 하나에 정보 하나
- 0~2초 훅: 질문형("속초에 이런 수영장이?") / 숫자형("1박 15만 원대 풀빌라 3곳") / 손해형("이거 모르면 손해")
- 흐름: 훅 → 대표 장면 → 가는 법 → 볼거리 2~3 → 숙소 → 정보 카드 2장 → 엔딩
- 자막 12자 이내, 2줄 이하, 숫자·가격은 주황, 굵은 고딕
- 0~2초 왼쪽 위 작은 글씨 "광고 · 제휴링크 포함"
- 엔딩(2~2.5초): 크림 배경 + 초록 "청귤트립" + 주황 "정보는 프로필 링크 #번호" + "구독하고 다음 여행도 같이 가요"
- 표현: "역대급 뷰", "무조건 가세요", "인생 숙소" 등 감성 표현은 적극 사용.
  "최저가·1위·가장 싼" 같은 가격·순위 최상급은 2단계 근거가 있을 때만 "{날짜} {사이트} 기준"을 붙여서. 근거 없으면 "가성비", "이 가격에?"로.
- 확인 안 된 사실(가격·시간·수온·층수·운영 기간) 금지. 규정·운영 정보에는 "OO년 OO월 기준" 작게 표기
- 타깃 A면 이동 편의·휴식 장면, 타깃 B면 야경·스파·사진 명소 장면 반드시 1개 이상
- 카메라(장면마다 하나, 연속 반복 금지, 훅은 클로즈업에서 시작):
  빠른 줌인 / 천천히 줌인 / 천천히 줌아웃 / 좌→우 패닝 / 우→좌 패닝 / 아래→위 틸트 / 위→아래 틸트 / 고정
- 효과: 수면 물결(수영장·바다), 김 피어오름(온천·온수풀·음식), 눈 내림, 낙엽, 빛 반짝임(야경), 글자 하나씩 등장(카드)
- 장면 전환: 0.3초 페이드, 일부 슬라이드
- 내레이션: 1초 4~5글자 이내, AI 음성 또는 본인 목소리(5060 타깃은 사람 목소리 권장)
- 음원: 저작권 문제 없는 음원만(유튜브 오디오 라이브러리, 인스타는 비즈니스 계정 사용 가능 음원·Meta 사운드 컬렉션)
- 사진 소스: 직접 촬영 / 숙소 허락 사진 / 공공누리 제1유형(출처 기재, 2·3·4유형 금지) / [AI]
  블로그·예약 사이트·남의 SNS 사진, 방송 화면 사용 금지. 사진은 가로 2000px 이상 원본 권장
- 영상 생성 도구: **Grok Imagine(xAI, 사진 → 영상)**. 사진이 첫 장면이 되고 물·김·커튼·빛·카메라만 움직이게 한다.
  전체 Grok 모드는 사진마다 6초 클립 → 가장 안정적인 2~3.5초만 사용 / 절약형은 훅·대표 장면 2컷만 Grok
  건물 모양·간판·가구가 바뀌거나 사람이 새로 생긴 클립은 폐기. 업로드 시 "변경되었거나 합성된 콘텐츠" 표시. 생성 전 비용(클립 수 × 초) 확인

출력 A. 장면표
| # | 시간 | 화면 | 카메라 | 효과 | 큰 자막 | 내레이션 | 사진 소스 |
+ 정보 카드: "이런 분께 추천" 3줄 / "가기 전 꼭 확인" 3줄(운영 시간·요금·예약 조건)

출력 B. 사진 확보 목록 (7~8장)
- 장면 / 구도(가로·세로, 피사체 위치) / 시간대(골든아워·야경) / 구할 곳
- 숙소 사진 요청 문자 초안: "안녕하세요, 여행 쇼츠 채널 청귤트립입니다. 유튜브 쇼츠로 숙소를 소개하고 싶은데 홍보용 사진을 사용해도 될까요? 출처는 영상 설명란에 표기하겠습니다."
- 숙소 영상 권장 순서: 수영장 → 노을·야경 → 라운지 → 창밖 풍경 → 객실 2종 → 디테일 → 조식·외관

출력 C. Grok Imagine 프롬프트 (장면마다, 영어, 사진 → 영상)
| 장면 # | 사진 파일 | 프롬프트 | 생성 길이(초) | 사용 구간 start/dur |
형식: "{카메라 움직임}. {움직일 것만 1~2개}. {빛·시간대}. Keep the building, room layout, furniture, signs and logos exactly as in the photo. No people added, no text, no new objects. Realistic travel footage, natural colors, smooth and stable, vertical 9:16."
마지막에 예상 생성량 합계(클립 수 × 초)를 적는다.
실행 명령: python tools/grok_video.py photos/01.jpg "<프롬프트>" clips/01.mp4 --duration 6
예: 수영장 "Only the water gently ripples, sunlight caustics shimmer on the pool floor. Slow dolly-in at water level."

    객실 "Sheer curtains sway gently, waves move outside the window. Slow dolly-in toward the window."
    단풍길 "Leaves fall slowly, branches sway. Slow forward dolly along the path. Golden hour."
    온천 "Steam rises softly, light snow falls. Slow push-in. Quiet winter evening."

출력 D. 렌더 파일 (사진 파일명이 있을 때, tools/shorts_render.py용 JSON만)
{"size":[720,1280],"fps":30,"transition":0.3,"badge":"광고 · 제휴링크 포함","scenes":[

 {"image":"파일","dur":2.2,"from":{"z":1.7,"cx":0.5,"cy":0.6},"to":{"z":1.3,"cx":0.5,"cy":0.55},"ripple":{"y0":0.65,"amp":5},"text":"자막","text_pos":"top|middle|bottom"},

 {"card":true,"bg":"파일","dur":3.0,"title":"가기 전 꼭 확인","lines":["","",""]},

- z: 1.0=사진에서 세로로 자른 최대 범위, 클수록 확대 / cx·cy: 화면 중심(0~1)
- 줌인 z 1.0→1.3, 줌아웃 1.45→1.0, 패닝 cx 0.2→0.8, 틸트 cy 0.7→0.3, 훅 z 1.6 이상

- 물이 있는 사진(Grok 미사용 시)은 ripple(y0 = 수면 시작 높이 0~1)
- 장면 길이 합계 − (장면 수−1)×0.3 = 29.5~31초
