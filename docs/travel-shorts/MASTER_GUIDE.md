# 여행 쇼핑쇼츠 수익화: 필요한 조건과 만들 것 전체 정리

> 작성일 2026-11-01. 앞서 claude.ai에서 만든 「여행 쇼핑쇼츠 수익화 가이드」, 「정보 수집 앱」, 「테마별 소재 + 제휴 업체」, 첫 대본(기차 단풍여행)을 검토하고 보완했습니다.
> 커미션 비율, 유튜브 자격 기준, 각 제휴사 심사 조건은 자주 바뀝니다. **가입할 때 각 공식 페이지에서 다시 확인하세요.**

## 0. 기존 전략 검토 결과

### 잘 된 점 (그대로 가져갑니다)
- 수익 구조 판단이 맞습니다. 여행 예약·eSIM이 큰 수익을 내고, 쿠팡은 건수를 채우고, 조회수 수익은 덤입니다.
- 출발 1~2개월 전에 예약 소재를 올린다는 시즌 선행 원칙
- "돈을 아껴준다"는 훅, 시리즈화, 클릭·전환 중심의 지표
- 첫 콘텐츠의 타깃 조합(5060 + 기차 + 단풍)과 플랫폼별 대본 분리

### 정확도 보완

| 항목 | 기존 내용 | 보완 |
|------|-----------|------|
| YPP 기본 조건 | 구독 1,000 + 쇼츠 90일 1,000만 회 또는 시청 4,000시간 | 시청 4,000시간은 **최근 12개월** 기준입니다. |
| YPP 하위 단계 | 구독 500, 업로드 3개, 쇼츠 300만 회 | 업로드 3개는 **최근 90일 공개 업로드**, 쇼츠 300만 회는 90일 기준이며, 대신 **긴 영상 시청 3,000시간(12개월)**으로도 됩니다. |
| 수익 예시 | 클릭률 0.3~1%, 구매율 3~5% | 숫자 자체는 무리가 없습니다. 다만 쇼츠는 **링크를 바로 누를 수 없어** (프로필·고정댓글로 한 번 더 이동) 초반 클릭률은 하한(0.3%) 쪽으로 잡는 게 안전합니다. |
| 여행 제휴 추적 | 언급 없음 | 여행 예약은 **며칠 뒤 앱에서 결제**하는 경우가 많아 쿠키 추적이 끊기기 쉽습니다. 쿠키 기간이 긴 곳(Travelpayouts 계열은 보통 30일 안팎)을 우선하고, 영상마다 **subId·UTM**을 달리 붙여서 어떤 영상이 팔았는지 구분하세요. |

## 1. 갖춰야 할 조건

### 1-1. 결정할 것 (사장님이 정해야 함)
- [ ] **채널 콘셉트**: 추천은 「5060 기차·국내여행 + 일본 근거리 여행」입니다. 첫 대본의 반응(12.5만)이 이쪽이고, 경쟁 채널이 2030 쪽보다 적습니다.
- [ ] **채널 계정**: 여행 전용 새 채널을 권합니다. 기존 harujin(생활)·shinjh(뷰티) 채널에 섞으면 알고리즘이 시청자를 헷갈립니다.
- [ ] **링크 허브**: 인포크에 여행 전용 페이지를 하나 더 만드는 걸 권합니다(예: `link.inpock.co.kr/<여행채널명>`). 이 저장소의 동기화 도구는 페이지 이름만 추가하면 쓸 수 있습니다.
- [ ] **얼굴·목소리**: 얼굴 노출 없이 AI 음성(Vrew 등)으로 갈지, 본인 목소리로 갈지. 5060 타깃은 사람 목소리가 신뢰도가 높습니다.

| 순서 | 가입처 | 왜 | 조건·준비물 |
|------|--------|-----|-------------|
| 1 | **쿠팡파트너스** | 여행용품 + 쿠팡 트래블(국내 숙소·입장권) | 즉시 가입. 일정 금액 이상 실적이 나면 최종 승인 후 **Open API 키** 발급 → 이 저장소의 딥링크 자동화가 실제로 돌아갑니다 |
| 2 | **마이리얼트립 파트너** | 국내외 투어·숙소, 한국인 비중 최대 | 운영 채널 URL 심사. 영상 몇 편이 올라간 뒤 신청하면 승인이 잘 납니다 |
| 3 | **Travelpayouts** | 클룩·KKday·겟유어가이드·아고다·eSIM·렌터카를 한 번에 | SNS 채널로도 가입 가능. 브랜드마다 별도 승인 |
| 4 | **아고다 파트너** (또는 Travelpayouts 경유) | 숙소 | 채널 심사 |
| 5 | **네이버 쇼핑커넥트** | 네이버 클립 상품 태그 | 네이버 클립 크리에이터 조건 확인 |
| 6 | 링크프라이스 / 애드픽 | 국내 여행사(하나·모두·노랑풍선), 여행자보험 CPA | 필요할 때 |

> 순서 팁: 영상 10편 정도를 먼저 올린 뒤 2~4번을 신청하세요. 빈 채널은 심사에서 떨어지기 쉽습니다. 그 사이에는 쿠팡 트래블 링크로 숙소·입장권을 대신 겁니다.

### 1-3. 플랫폼 정책 조건

| 플랫폼 | 링크를 어디에 | 지켜야 할 것 |
|--------|---------------|--------------|
| 유튜브 쇼츠 | 고정댓글, 채널 프로필 링크, 쇼츠 설명란(누를 수 없음) | "유료 광고 포함" 체크, 합성 콘텐츠 표시, 재사용 콘텐츠 판정 피하기(아래) |
| 유튜브 쇼핑 제휴 | 쇼츠에 상품 태그 | YPP 가입 + 별도 자격. 한국은 쿠팡 등 제휴 스토어 연동 방식이라 조건이 자주 바뀝니다 |
| 인스타 릴스 | 프로필 링크, 스토리 링크 스티커 | "유료 파트너십" 또는 캡션 첫 줄 `#광고`, 사용 가능 음원만 |
| 틱톡 | 프로필 링크(팔로워 조건 있음) | 콘텐츠 공개 설정의 "브랜드 콘텐츠" 표시 |
| 네이버 클립 | 쇼핑커넥트 상품 태그 | 광고 표시, 검색형 제목 |

**재사용 콘텐츠 판정 피하는 법**: 같은 템플릿을 쓰더라도 편마다 ① 장소·상품이 다르고 ② 내레이션이 새로 쓰였고 ③ 본인 의견·정보(가격, 가는 법)가 들어가야 합니다. 사진 슬라이드만 바꿔 끼운 영상을 대량으로 올리면 수익 창출이 막힐 수 있습니다.

### 1-4. 법·세금

- **광고 표시** (공정위 추천·보증 심사지침): 제목 또는 설명란 첫 줄 + 영상 안 자막. 한글로, 알아보기 쉬운 크기로. "협찬"·"제휴" 같은 모호한 말보다 **"광고"**를 쓰세요.
- **표시 문구 예시**
  - 공통: `광고 | 이 영상의 링크로 예약·구매하면 제휴 수수료를 받을 수 있습니다.`
  - 쿠팡 링크가 있을 때 추가: `이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.`
- **허위·과장 금지**: "최저가", "무조건 이득" 같은 표현은 근거(날짜와 가격 비교 화면)가 있을 때만 씁니다. 운행·가격 정보에는 "OO월 OO일 기준"을 붙이세요.
- **저작권**: 직접 촬영, 공공누리 제1유형, 라이선스 구매, AI 생성만 씁니다. 방송 화면, 남의 쇼츠, 일반 가요는 쓰지 않습니다.
- **초상권**: 직접 촬영할 때 모르는 사람 얼굴이 크게 나오면 흐림 처리합니다.
- **세금**: 제휴 수익은 보통 사업소득(3.3% 원천징수)으로 들어옵니다. 계속 반복해서 벌면 **1인 미디어 창작자로 사업자등록**을 검토하세요(업종코드 940306 면세 / 921505 과세, 장비·인력 규모에 따라 다름). 이듬해 5월 종합소득세 신고 대상입니다. 정확한 판단은 세무사 상담을 권합니다.

### 1-5. 장비·도구
- 필수: 스마트폰(4K 30fps), CapCut 또는 Vrew, Canva 또는 미리캔버스
- 있으면 좋음: 짐벌(직접 촬영 시), 핀마이크(본인 목소리 시)
- 이미 연결돼 있는 것: Higgsfield(쇼핑숏츠 제작, 바이럴 예측), Buffer·Typefully(예약 게시), 이 저장소의 쿠팡 딥링크와 인포크 동기화 도구

## 2. 만들어야 할 것 전체 목록

- [ ] 인포크 여행 페이지: 섹션을 **테마별**(이번 주 단풍 / 겨울 온천 / 해돋이 / 여행 준비물)로 나누고, 영상 번호를 카드 제목에 넣기(예: `#01 기차 단풍 숙소`)

- [ ] 썸네일·자막 템플릿 3종 (리스트형, 비교형, 가격형). 폰트·색은 통일

### 2-2. 콘텐츠 (반복)
- [ ] **대본 30개 기획표** (테마, 훅, 장소·상품 3~5개, 연결 링크, 업로드 예정일)

- [ ] 숙소 1~2개(아고다/쿠팡 트래블), 투어 1개(마이리얼트립/클룩), 쿠팡 준비물 2~3개

## 4. 역할 분담: Claude가 할 수 있는 것 / 사장님이 해야 하는 것

### Claude가 이 세션에서 바로 할 수 있는 것
- 대본 30개 기획표와 편별 대본(4개 플랫폼 버전), 설명란, 해시태그, 고정댓글
- 쿠팡 여행용품 검색 → 상품 목록 등록 → 대본 5개 후보 작성 (이 저장소의 `search`, `script` 명령)
- 인포크 링크 카드 동기화 **시험 실행**(실제 반영 없이)
- 올려주신 사진으로 쇼츠 영상 제작, 내레이션 음성, 바이럴 예측 (크레딧이 드는 작업은 금액을 먼저 확인받고 진행)
- 연결된 Buffer·Typefully 계정으로 게시 예약 (계정 연결은 사장님이 해야 함)
- 매주 성과 추적표 분석과 다음 주 기획

### 사장님이 해야 하는 것 (본인 인증·로그인·결정이 필요)
- 채널 개설, 각 제휴사 가입·정산 계좌 등록, 쿠팡파트너스 API 키 발급 후 `.env`에 입력
- 인포크 로그인 정보 입력과 첫 실제 동기화 전 셀렉터 보정(`docs/CALIBRATION.md`)
- 공공누리 사진 다운로드(회원 로그인 필요), 직접 촬영
- 최종 업로드 버튼, 유료 광고·합성 콘텐츠 표시 체크
- 세금·사업자등록 판단

### 현재 이 환경에서 막혀 있는 것
- 연합뉴스TV, 한국관광공사, 국립공원공단, 위키미디어 사이트 접속(네트워크 정책). 클라우드 환경 설정의 Network access에서 허용 도메인을 추가하면 풀립니다.
