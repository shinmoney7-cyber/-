## 확인 순서
1. 위 표의 인스타·유튜브 링크를 눌러 아이디가 비어 있는지 확인
2. 틱톡도 같은 아이디로: `https://www.tiktok.com/@아이디`
3. 유튜브 앱에서 채널 이름(한글)으로 검색해 비슷한 여행 채널이 있는지 확인
4. 오래 쓸 이름이면 특허정보검색서비스 KIPRIS(kipris.or.kr)에서 상표 등록 여부 확인 (41류 여행 정보 제공 / 39류 여행 알선)
5. 정하면 세 플랫폼 아이디를 **같은 날 한꺼번에** 선점

- 인스타: 영문 소문자, 숫자, `.`, `_`, 30자 이내
