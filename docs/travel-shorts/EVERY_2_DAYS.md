### 예상 수익 점수 (AI가 후보를 줄 세울 때 쓰는 식)
```
수익 점수 = 객단가 점수(1~5) × 수수료 점수(1~5) × 구매 가능성(1~5) × 시즌 수요(1~5)
- 객단가: 해외 다박 숙소 5 / 국내 고급 숙소 4 / 입장권·투어 3 / 국내 펜션 3 / 용품 1
- 수수료: 제휴사 대시보드 수수료율 기준 (모르면 숙소·투어 3, eSIM·보험 4, 쿠팡 2)
- 구매 가능성: "예약 직전 정보"(가는 법·가격 비교·예약 팁) 5 / 감성 소개 3 / 볼거리만 2
- 시즌 수요: 업로드 4~12주 뒤가 성수기 5 / 비수기 1
```

## 4. 로테이션 규칙 (다양하게)
1. **월 15편 배분:** S 6편(40%) / A 5편(33%) / B 3편(20%) / C 1편(7%)
2. **같은 시즌 안에서는 S → A → B → C 순서.** 단, 연속 3편이 모두 해외가 되지 않게 4편째에 국내를 끼운다.
3. **같은 지역(도시)은 14일 안에 반복 금지.** 같은 나라는 연속 2편까지.
4. **재생목록은 연속 두 번 같은 것 금지.**
5. **타깃 번갈아:** 5060·가족 → 커플 → 5060·가족 … (가족 성수기에는 2:1까지 허용)
6. **이동 수단 섞기:** 2주(7편)에 기차·자동차·비행기가 각각 1편 이상.
7. **날짜 확정 축제**는 2~4주 전, **해외 성수기**는 6~12주 전에 올린다. 늦었으면 "지금이라도 예약하는 법"으로 각도를 바꾼다.
