# 역전극장 1편 — 구글 플로우 제작 세트

**제목:** 청소부 할머니에게 "꺼지라"던 명품관 매니저의 최후

- 장면 9개 × Veo 3.1 Lite(10 크레딧) = **90 크레딧**
- 무료로 하면 하루 50 크레딧 → **1일차 1~5번, 2일차 6~9번**
- 각 장면은 8초로 생성되고, 합칠 때 약 6초로 잘라 전체 약 55초로 맞춥니다

## 0. 준비 (처음 한 번만)

1. **labs.google/flow** 접속 → 구글 로그인 → **새 프로젝트**
2. 화면 비율 **세로 9:16**, 모델 **Veo 3.1 – Lite** 선택
3. **재료(Ingredients)**에 캐릭터 사진 4장 올리기
   - `할머니` · `매니저` · `대표` · `막내직원`
   - 사진은 채팅에 보낸 Higgsfield 갤러리에서 내려받기
4. 각 장면의 **"넣을 재료"**에 적힌 사진만 골라 넣고, 프롬프트를 통째로 붙여넣기 → 생성

> 결과가 마음에 안 들면 같은 프롬프트로 한 번 더 생성하세요. 입모양이나 한국어 발음이 어색한 경우가 가끔 있습니다.
