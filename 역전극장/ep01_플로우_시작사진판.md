# 역전극장 1편 — 플로우 남은 장면 (시작 사진 방식)

이미 완성: **장면 1**(향수 매니저), **장면 3**(무릎 꿇고 닦는 할머니)

남은 장면: **9개 × 10 크레딧 = 90 크레딧** (Veo 3.1 Lite)
- 1일차: 2-1, 2-2, 4, 5, 6
- 2일차: 7-1, 7-2, 8, 9

## 만드는 법 (모든 장면 동일)

1. Flow 프로젝트 화면 아래 입력창 왼쪽 **+** → **이미지 추가** → 해당 **시작 사진**을 고르고 **첫 프레임(시작 프레임)**으로 지정
2. 아래 프롬프트를 통째로 붙여넣기
3. 설정이 **9:16 · x1 · Veo 3.1 Lite**인지 확인 → 생성
4. 마음에 들면 **↓ → 720p 원본 크기**로 받고, 파일 이름을 장면 번호로 바꾸기 (예: `02-1.mp4`)

> 사진이 구도를 정해 주므로 프롬프트는 **움직임과 대사만** 짧게 적었습니다.
> 한 장면에 **말하는 사람 1명, 동작 1개**만 넣었습니다.
