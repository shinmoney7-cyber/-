# 숏폼 PRO 기획안

업종·플랫폼·목적을 받아, 광고주에게 바로 보여줄 수 있는 숏폼 광고 기획안 8종을 만든다.
호출: `/shortform-pro` 또는 "숏폼 기획안 만들어줘", "숏폼 PRO", "카페 숏폼 광고 기획".

## 진행 체크리스트

- [ ] 1. 필수 3가지 묻기 — 업종, 플랫폼, 목적
- [ ] 2. 선택 항목 묻기 — 타깃 페르소나, KPI, 예산 (모르면 넘어가고 가정값을 표시)
- [ ] 3. 8종 산출물 작성
- [ ] 4. 검사 → 고치기 → 통과해야 전달

## 1. 필수 질문

한 번에 하나씩, 선택지 3~4개와 추천 1개를 붙여 묻는다.
- 업종 (예: 카페, 뷰티샵, 음식점, 쇼핑몰)
- 플랫폼 (인스타 릴스 / 유튜브 쇼츠 / 틱톡 / 여러 개)
- 목적 (방문·매출 / 팔로워 / 브랜드 인지 / 이벤트 홍보)

## 2. 선택 질문

타깃 페르소나, KPI, 예산은 선택이다. 답이 없으면 업종·목적에 맞는 가정값을 쓰고, 산출물에 "가정값"이라고 표시한다.

## 3. 산출물 8종

1. **인스타 캡션 3종** — 감성형 / 정보형 / 후킹형, 각각 해시태그 포함
2. **촬영 가이드 & 컷 자막** — 컷 번호, 길이(초), 화면, 자막 문구 표
3. **편집 브리핑** — 길이, 컷 템포, BGM 무드, 자막 스타일
4. **알고리즘 전략** — 1번에서 고른 플랫폼별로 업로드 시간, 첫 3초 훅, 해시태그 개수
5. **시리즈 캘린더** (선택) — 4주 업로드 일정과 회차별 주제
6. **예산 & ROI** — 항목별 비용과 예상 성과를 최솟값~최댓값 범위로. 근거 없는 숫자를 확정값처럼 쓰지 않는다
7. **광고주 확인서** — 산출물 요약, 일정, 비용, 수정 횟수, 확인 서명란
8. **제작팀 브리핑** — 담당별 할 일, 마감일, 준비물

## 4. 검사 → 고치기 → 반복

전달 전에 아래 기준으로 검사한다:
- 8종(선택 안 한 시리즈 캘린더는 빼도 됨)이 모두 있는가
- 1번에서 고른 플랫폼·목적이 모든 산출물에 맞게 반영됐는가
- 가정값에 "가정값" 표시가 붙어 있는가
- 효과·수치를 과장하거나 지어내지 않았는가 (예상치는 범위로)
- 캡션 3종의 톤이 서로 다른가

미통과 항목은 해당 산출물만 고치고 다시 검사한다. 전부 통과해야 전달한다.
이 기준에 없는 이유로 고쳤다면, 작업 끝에 새 기준 1개를 제안하고 사용자 승인을 받는다.

## 대화 톤

정중한 한국어, 간결하게. 질문은 한 번에 하나.
