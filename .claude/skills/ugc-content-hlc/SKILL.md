# UGC 홍보영상 대본·자막·음량 세세 분석 스킬

## 목적

상품 정보를 받아 **욕망·욕구 4층 분석 → 후킹 전략 선정 → 카테고리 맞춤 UGC 시나리오 5종** 을 생성한다.  
각 시나리오에는 씬 구조도·대본·자막 타이밍·배경음악·음량 레벨표·CTA가 포함된다.

---

## STEP 0 — 입력 수집

사용자에게 다음을 요청한다 (한 번에 묻기):

```
📦 상품명:
🔗 상품 URL:
🖼️  이미지 URL (or 직접 첨부):
🗂️  카테고리: [과일별 / 뷰티 / 육아 / 일상생활 / 욕실용품 / 주방용품 / IT·전자기기 / 건강·다이어트]
🎯  주요 타겟: (예: 30대 주부, 20대 직장인, 육아 중인 엄마 등)
💰  가격대: (예: 9,900원, 프리미엄)
✨  핵심 USP(차별점): (예: 무설탕, 국내산, 30초 완성)
📱  노출 플랫폼: [인스타 릴스 / 유튜브 쇼츠 / 틱톡 / 전체]
```

정보가 없는 항목은 카테고리와 상품명으로 추론해서 채운다.

---

## STEP 1 — 욕망·욕구 4층 분석

카테고리별 욕망 레이어를 분석한다.

### 욕망 4층 구조

| 레이어 | 내용 | 예시 |
|--------|------|------|
| L1 기능적 욕구 | 상품이 해결하는 실질 문제 | 기름때 제거, 수분 공급 |
| L2 감정적 욕구 | 사용 후 느끼는 감정 | 뿌듯함, 상쾌함, 안도감 |
| L3 사회적 욕구 | 타인에게 보여지는 모습 | "관리하는 사람", "좋은 엄마" |
| L4 자아 정체성 욕구 | 나다움·가치관과의 연결 | 건강한 삶, 스마트한 소비 |

### 카테고리별 핵심 욕망 키

**과일별**
- L1: 신선함, 영양, 맛, 무농약
- L2: 건강해지는 느낌, 행복감, 계절감 만끽
- L3: "건강 챙기는 사람", "가족 잘 먹이는 사람"
- L4: 자연과 연결, 건강한 삶의 추구

**뷰티**
- L1: 피부 개선, 커버력, 지속력, 성분
- L2: 자신감, 설렘, 변신의 쾌감
- L3: "예쁜 사람", "피부 좋은 사람", "트렌디한 사람"
- L4: 나를 사랑하는 루틴, 여성성·개성 표현

**육아**
- L1: 안전, 편의, 시간 절약, 발달 도움
- L2: 안도감, 죄책감 해소, 아이 행복한 모습에 기쁨
- L3: "좋은 부모", "스마트한 육아맘/육아파"
- L4: 아이에게 최선을 다하는 부모로서의 정체성

**일상생활**
- L1: 편리함, 시간 절약, 비용 절감
- L2: 생활이 정돈되는 만족감, 여유
- L3: "살림 잘하는 사람", "효율적인 사람"
- L4: 나를 위한 소소한 사치, 일상의 업그레이드

**욕실용품**
- L1: 청결, 위생, 수납, 편리
- L2: 상쾌함, 정갈한 공간에서의 힐링
- L3: "깔끔한 사람", "인테리어 신경 쓰는 사람"
- L4: 나만의 공간을 가꾸는 나

**주방용품**
- L1: 요리 편의, 세척 편의, 내구성
- L2: 요리의 즐거움, 성취감, 가족에 대한 사랑 표현
- L3: "요리 잘하는 사람", "알뜰한 살림꾼"
- L4: 손수 음식 만드는 가치, 가족과의 연결

**IT·전자기기**
- L1: 성능, 생산성 향상, 편의, 배터리·속도
- L2: 최신 기기 소유의 설렘, 능률 오를 때 쾌감
- L3: "얼리어답터", "스마트한 사람", "트렌드 아는 사람"
- L4: 기술로 삶을 진화시키는 나

**건강·다이어트**
- L1: 체중 감량, 영양 보충, 체력 향상
- L2: 변해가는 몸에 대한 뿌듯함, 자기 효능감
- L3: "자기 관리하는 사람", "의지력 있는 사람"
- L4: 건강한 몸으로 살고 싶은 진짜 나

## STEP 2 — 후킹 전략 5종 선정

각 시나리오에 아래 후크 유형 중 하나를 배정한다:

| 후크 유형 | 설명 | 0~1초 오프닝 형태 |
|-----------|------|-------------------|
| **A. 충격·반전** | 예상을 뒤엎는 장면·사실 | "이거 진짜예요?" 하며 결과 먼저 공개 |
| **B. 공감·문제** | "나만 그래?" 공감 유발 | "이 문제 겪고 계신 분?" 상황 재연 |
| **C. 궁금증·비밀** | 정보 격차 자극 | "이걸 몰랐다면 손해" 미스터리 인트로 |
| **D. 결과 선공개** | Before/After 결과 먼저 | 변신 후 모습 → "어떻게 된 거야?" |
| **E. 사회적 증거** | 숫자·입소문·유행 강조 | "이번 달 OO만 명이 산 거" 통계 오프닝 |

## STEP 3 — 카테고리 맞춤 UGC 시나리오 5종 생성

각 시나리오를 다음 포맷으로 출력한다:

---

### 🎬 시나리오 [번호] — [후크 유형명] 버전

**[전체 컨셉 한 줄]**

#### 씬 구조도

| 씬 | 시간 | 화면 묘사 | 카메라/앵글 |
|----|------|-----------|-------------|
| S1 | 0~2s | ... | ... |
| S2 | 2~6s | ... | ... |
| S3 | 6~11s | ... | ... |
| S4 | 11~14s | ... | ... |
| S5 | 14~15s | ... | ... |

#### 대본 (보이스오버 / 자막용)

```
[0~2s] (오프닝 후크)
"___"

[2~6s] (문제 또는 전개)
"___"

[6~11s] (상품 소개 / 클라이맥스)
"___"

[11~14s] (결과·증거)
"___"

[14~15s] (CTA)
"___"
```

#### 자막 타이밍표

| 자막 번호 | 시작 | 종료 | 텍스트 | 위치 | 폰트 스타일 |
|-----------|------|------|--------|------|------------|
| 1 | 0.0s | 1.5s | ... | 상단 중앙 | 굵게, 40pt |
| 2 | 2.0s | 4.5s | ... | 중앙 | 일반, 32pt |
| ... | ... | ... | ... | ... | ... |

**자막 원칙**
- 한 화면에 최대 2줄, 줄당 최대 12자
- 핵심 키워드는 색상 강조 (예: 노랑 or 빨강)
- 말보다 0.2~0.3s 먼저 표시

#### 음량 레벨표

| 트랙 | 구간 | dB | % | 비고 |
|------|------|----|----|------|
| BGM | 0~2s (오프닝) | -18 dB | 30% | 에너지 있게 시작 |
| BGM | 2~12s (전개) | -24 dB | 20% | 보이스오버 뒤로 |
| BGM | 12~15s (엔딩) | -18 dB | 30% | 다시 업리프트 |
| 보이스오버 | 전구간 | -6 dB | 85% | 명확하게 |
| SFX (전환효과) | 씬 전환마다 | -12 dB | 50% | 짧게 0.2s |
| SFX (강조음) | 결과 공개 순간 | -9 dB | 60% | 임팩트 |

**BGM 추천 장르** (카테고리별):
- 과일·건강: 밝은 어쿠스틱, Lo-fi chill
- 뷰티: Trendy pop, 감성 신스
- 육아: 따뜻한 피아노, 밝은 동요 리믹스
- 일상·주방·욕실: 경쾌한 팝, Upbeat indie
- IT·전자기기: Electronic, Futuristic beat
- 건강·다이어트: Motivational hip-hop, Energy EDM

#### 광고 문구 & CTA

```
광고 문구: "___"
CTA 버튼 텍스트: "지금 바로 보기 →"
링크 위치: 영상 하단 or 프로필 링크
해시태그: #___ #___ #___
```

## STEP 4 — 플랫폼별 최적화 가이드

### 인스타그램 릴스
- 세로 9:16 필수
- 첫 0.5s 안에 움직임 시작
- 자막 필수 (무음 시청자 40%)
- BGM: 인스타 트렌딩 오디오 사용 권장

### 유튜브 쇼츠
- 9:16, 60초 이하 (15s 최적)
- 제목에 핵심 키워드 포함
- 첫 화면에 썸네일급 비주얼

### 틱톡
- 0~1s 후크가 가장 중요
- 텍스트 오버레이 + 말 속도 빠르게
- 트렌드 사운드 사용시 발견 확률 3배

## STEP 5 — 출력 완성 후 안내

5개 시나리오 출력 후:

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📋 5개 UGC 시나리오가 완성되었습니다.

원하시는 작업을 선택하세요:
① [번호] 선택 → 탑뷰(TopView) 제작 패키지 생성
② [번호] 선택 → 구글 Flow 제작 패키지 생성
③ [번호] 선택 → 자막 파일(.srt) 전체 출력
④ 전체 시나리오 → 다른 카테고리로 재생성
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

사용자가 번호를 선택하면 `/topview-shorts` 또는 `/google-flow-shorts` 스킬로 연계한다.
