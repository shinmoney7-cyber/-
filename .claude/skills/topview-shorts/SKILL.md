# TopView 쇼핑 숏츠 제작 스킬

## 목적

상품 정보 → UGC 대본 5종 생성 → 사용자 선택 → **TopView.ai 입력용 완성 패키지** 출력.  
필요시 `/ugc-content-hlc` 스킬의 욕망·후킹 분석을 선행 실행한다.

---

## STEP 0 — 상품 정보 수집

아래 정보를 한 번에 묻는다:

```
📦 상품명:
🔗 상품 URL (쿠팡/네이버 등):
🖼️  상품 이미지 URL:
🗂️  카테고리:
    1) 과일별  2) 뷰티  3) 육아  4) 일상생활
    5) 욕실용품  6) 주방용품  7) IT·전자기기  8) 건강·다이어트
✨  핵심 USP(차별점 1~2개):
💰  가격 (표시할 경우):
🎵  BGM 분위기: [밝고 경쾌 / 감성적 / 강렬·에너지 / 따뜻함 / 기본(자동)]
```

정보가 부족한 항목은 카테고리로 추론해 채운다.

## STEP 1 — 카테고리별 비주얼 & 분위기 설정

### 카테고리 비주얼 가이드

| 카테고리 | 배경 스타일 | 색감 | 촬영 앵글 | 분위기 키워드 |
|---------|------------|------|-----------|--------------|
| 과일별 | 자연광, 나무 테이블 | 싱그러운 초록·오렌지 | 탑뷰 + 클로즈업 | 신선, 풍성, 생동감 |
| 뷰티 | 화이트 미니멀, 꽃·파우더 소품 | 핑크·베이지·골드 | 정면 + 슬로우줌 | 우아, 설렘, 변신 |
| 육아 | 파스텔 방, 장난감 소품 | 소프트 파스텔 | 아이 시선 높이 | 따뜻함, 안전, 행복 |
| 일상생활 | 집 실내, 일상 공간 | 내추럴·화이트 | 손 클로즈업 | 편리, 심플, 정돈 |
| 욕실용품 | 타일·욕실 배경 | 민트·화이트·실버 | 탑뷰 + 사이드 | 청결, 상쾌, 힐링 |
| 주방용품 | 주방 카운터, 요리 중 장면 | 따뜻한 우드·크림 | 클로즈업 액션 | 풍성, 맛있음, 즐거움 |
| IT·전자기기 | 다크 or 미니멀 책상 | 블랙·실버·딥블루 | 45° 제품샷 + 화면 | 세련, 혁신, 파워 |
| 건강·다이어트 | 운동 공간 or 주방 | 활기찬 그린·화이트 | 전신 + 클로즈업 | 활력, 변화, 성취 |

## STEP 2 — UGC 시나리오 5종 생성

다음 5가지 후크 전략으로 시나리오를 생성한다:

### 시나리오 1 — 충격·반전 후크 (결과 선공개)
```
씬 구조:
[0~1s]  결과/After 장면 먼저 공개 (시청자 멈춤 유도)
[1~4s]  "이게 가능한 이유는..." 상품 등장
[4~9s]  핵심 기능 3가지 빠르게 시연
[9~13s] 사용 후 만족 반응 (표정·리액션)
[13~15s] CTA + 가격 텍스트

대본:
"[결과 장면 보여주며] 이거 진짜예요?
[상품 등장] 이 [상품명] 쓰고 나서 진짜 달라졌어요.
[기능 시연] [USP 1], [USP 2], 그리고 [USP 3]까지.
[만족 반응] 이제 이거 없으면 안 되겠어요.
[CTA] 링크에서 확인해보세요 ↓"
```

### 시나리오 2 — 공감·문제 후크 (나만 그래?)
```
씬 구조:
[0~2s]  공감 유발 문제 상황 재연 (시청자 "나도!" 반응)
[2~5s]  문제 해결 전환 → 상품 등장
[5~10s] 상품으로 해결되는 장면 시연
[10~13s] "이렇게 쉬울 줄 몰랐어요" 반응
[13~15s] CTA

대본:
"[문제 재연] [공감 상황]... 저만 이런 거 아니죠?
[상품 등장] 근데 이거 쓰고 나서 진짜 해결됐어요.
[시연] [기능 시연 장면]
[반응] 이렇게 편할 줄 몰랐어요.
[CTA] 프로필 링크 확인해보세요!"
```

### 시나리오 3 — 궁금증·비밀 후크 (이걸 몰랐다면?)
```
씬 구조:
[0~1.5s] "이거 모르면 손해" 텍스트 + 신비로운 박스/패키지
[1.5~5s] 천천히 언박싱 or 첫 사용 장면
[5~11s]  기능별 디테일 클로즈업
[11~14s] "진작 알았으면 좋았을 텐데" 반응
[14~15s] CTA

대본:
"이거 모르면 진짜 손해예요.
[언박싱] [상품명] 처음 써보는 날...
[기능] 이 기능이랑, 이 부분이랑, 여기 디테일까지.
[반응] 진작 살 걸 그랬어요.
[CTA] 지금 링크에서 →"
```

### 시나리오 4 — 사회적 증거 후크 (OO명이 선택)
```
씬 구조:
[0~2s]  숫자·통계 텍스트 강조 ("이번 달 OO명이 구매")
[2~6s]  실제 사용 장면 (리얼 UGC 느낌)
[6~11s] 구체적 결과·수치 공개
[11~14s] "저도 반신반의했는데..." 솔직한 리뷰
[14~15s] CTA

대본:
"이번 달에만 [숫자]명이 선택한 거 알고 계세요?
[사용 장면] 저도 처음엔 반신반의했거든요.
[결과] 근데 [구체적 결과/수치] 이게 진짜예요.
[리뷰] 이제 주변에 다 추천하고 있어요.
[CTA] 링크 달아놨어요 ↓"
```

### 시나리오 5 — 변신·감정 후크 (Before → After 감동)
```
씬 구조:
[0~2s]  Before 상태 (문제 상황, 칙칙한 분위기)
[2~7s]  상품 사용 중 장면 (전환 효과)
[7~12s] After 상태 (확연한 차이)
[12~14s] 감정적 반응 (진심 담긴 표정)
[14~15s] CTA

대본:
"[Before] 솔직히 [문제 상황]이었어요.
[사용 중] 근데 [상품명] 쓰기 시작하고...
[After] 이렇게 달라졌어요. 진짜로.
[감정] [진심 어린 한 마디]
[CTA] 여러분도 해보세요 →"
```

## STEP 3 — 선택 후 TopView 입력 패키지 완성

사용자가 번호를 선택하면 아래 패키지를 출력한다:

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🎬 TopView 입력 패키지 — 시나리오 [번호]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【Script (영어 번역 + 한국어)】
EN: "..."
KR: "..."

【Visual Prompt (TopView 이미지 생성용)】
Scene 1 (0~Xs): [TopView 프롬프트 형식으로]
Scene 2 (Xs~Xs): [...]
...

【Caption / Subtitle】
[0.0s~1.5s] "..."
[2.0s~4.5s] "..."
...

【BGM Style】
Genre: [장르]
Mood: [분위기]
BPM: [대략 BPM]
TopView BGM 태그: [관련 태그]

【음량 설정값】
BGM 오프닝: 30% / -18dB
BGM 전개: 20% / -24dB
BGM 엔딩: 30% / -18dB
VO: 85% / -6dB
SFX 전환: 50% / -12dB
SFX 강조: 60% / -9dB

【CTA 텍스트】
메인: "..."
서브: "..."
해시태그: #... #... #...

【TopView 설정 요약】
- 영상 길이: 15초
- 화면비: 9:16 (세로)
- 자막 위치: 하단 80%
- 텍스트 애니: 팝업 or 슬라이드
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 카테고리별 후킹 포인트 빠른 참조

| 카테고리 | 최강 후크 | 핵심 감정 | 추천 시나리오 |
|---------|----------|-----------|--------------|
| 과일별 | 신선도 비주얼 충격 | 건강·풍성함 | 1번 또는 5번 |
| 뷰티 | Before/After 변신 | 자신감·설렘 | 5번 또는 3번 |
| 육아 | 아이 행복 반응 | 안도·기쁨 | 2번 또는 5번 |
| 일상생활 | 편의성 시연 | 편리·만족 | 2번 또는 4번 |
| 욕실용품 | 청결 비주얼 | 상쾌·힐링 | 1번 또는 5번 |
| 주방용품 | 요리 과정 클로즈업 | 즐거움·맛 | 2번 또는 3번 |
| IT·전자기기 | 성능 수치 공개 | 설렘·파워 | 4번 또는 1번 |
| 건강·다이어트 | 변화 수치·Before/After | 성취·자신감 | 5번 또는 4번 |
