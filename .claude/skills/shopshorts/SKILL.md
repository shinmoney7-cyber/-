# 쇼핑쇼츠 자동 생성 스킬

> **트리거**: `/shopshorts` 또는 "쇼핑쇼츠 만들어줘" + 상품 URL·이름

이 스킬은 `/home/user/-/쇼핑쇼츠_자동생성기.html` 앱의 워크플로우를 Claude 대화에서 바로 실행하는 가이드다.

---

## 입력

- **필수**: 상품 URL (쿠팡·네이버·11번가 등) **또는** 상품명
- **선택**: 강조 포인트, 타깃 (예: "20대 여성", "가성비 강조")

## 6단계 워크플로우

### 1단계 — 상품 정보 수집

상품 URL이 있으면 WebFetch로 페이지를 크롤링해 아래 항목을 추출:
- 상품명, 가격, 주요 스펙, 핵심 혜택
- 상품 이미지 URL
- 쿠팡 파트너스 링크 (있으면 그대로 사용)

URL이 없으면 상품명으로 검색하거나 사용자에게 URL을 요청.

### 2단계 — 타깃 & 욕망 포인트 결정

아래 기준으로 타깃 페르소나 1개를 선택:
| 카테고리 | 기본 타깃 |
|---|---|
| 뷰티·패션 | 20-30대 여성 |
| 전자·가젯 | 20-40대 남성 |
| 주방·생활 | 30-40대 주부 |
| 건강·운동 | 25-45대 남녀 공통 |
| 유아·교육 | 30대 부모 |

욕망 포인트 (하나 선택):
- 문제 해결 / 시간 절약 / 자기 과시 / 가성비 / 한정 수량

### 3단계 — 대본 생성

15초 숏폼 대본 구조 (5개 패널):
```
[0:00] 훅 — 강렬한 첫 마디 (문제·궁금증·놀라움)
[0:03] 문제 공감 — "이런 경험 있지?"
[0:07] 솔루션 — 상품 핵심 기능 1-2가지
[0:11] 증거 — 가격·스펙·후기 수치
[0:14] CTA — "지금 링크에서 확인해봐"
```

대본 작성 규칙:
- 각 줄 앞에 `[분:초]` 타임스탬프 필수
- 한 줄당 20자 이내 (자막 가독성)
- 음성: 빠르고 열정적인 톤
- 사실만 기재 (허위 과장 금지)

### 4단계 — 해시태그 & 캡션 생성

```
캡션 = 훅 문장 + 핵심 혜택 1줄 + CTA + 상품 링크
해시태그 = #쇼핑 #추천 #[카테고리] #[상품명] #쿠팡 (5-10개)
```

### 5단계 — 앱 실행 가이드 제시

사용자에게 앱 실행 방법 안내:

1. `/home/user/-/쇼핑쇼츠_자동생성기.html` 브라우저로 열기
2. Tab1 "쇼츠 생성" → 상품 URL 붙여넣기 → AI 자동완성
3. 대본 편집 (대본 텍스트 바 활용: 타임스탬프·이모지·자동타임)
4. "🎨 고급 편집"으로 자막 스타일 커스터마이징
5. "🎬 쇼츠 영상 생성" 클릭 → `.webm` 다운로드
6. 게시 섹션 → 플랫폼 선택 → "🚀 전체 게시"

### 6단계 — 결과 요약 & 다음 액션

생성한 항목을 정리해서 보여줌:
- 대본 전문 (타임스탬프 포함)
- 캡션 + 해시태그
- 앱 사용 팁 (어떤 설정 추천하는지)
- 플랫폼별 최적화 포인트

- 반말 사용 (존댓말 금지)
