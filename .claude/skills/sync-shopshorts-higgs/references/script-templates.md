## 1. 조사 기준과 한계

이번 조사는 YouTube 채널의 실제 Shorts 탭에서 공개 조회수가 높은 상품형 영상을 수집해 대사와 화면을 분해했다.

확인한 것:

- 공개 조회수
- 영상 길이
- 업로드 날짜
- 첫 장면과 첫 대사
- 상품 등장 시점
- 문제, 시연, 결과, CTA의 순서
- 자막과 화면 구성

확인할 수 없는 것:

- 실제 YouTube Shopping 상품 태그 클릭률
- 매출과 전환율
- 유료 광고로 발생한 조회수 비중
- 평균 시청 지속시간과 반복 재생률

따라서 `조회수가 높다 = 상품 전환율도 높다`고 단정하지 않는다. 아래 템플릿은 공개 성과 영상에서 반복된 시청 유지 구조를 추출한 것이다.

## 3. 반복된 조회수 구조

### 3.1 첫 2초에 제품 설명이 아니라 사건이 나온다

반복된 훅은 다섯 종류였다.

```text
불가능해 보이는 성능
비정상적으로 싼/비싼 가격
눈앞에서 벌어지는 변화
내가 겪는 구체적인 불편
몇 가지를 보여준다는 숫자 약속
```

`오늘 소개할 제품은`으로 시작한 사례보다 `동전을 자른다`, `20만 원짜리 사탕`, `1인분 90원`처럼 결과와 숫자가 먼저 나온 영상이 강했다.

### 3.2 형용사보다 증거 화면이 빠르다

- 절삭력은 실제로 자르는 화면
- 충전 속도는 타이머와 숫자
- 샤워기는 오염된 필터와 수압 비교
- 식품은 조리, 시식, 표정
- 뷰티는 얼굴에 바른 결과
- 생활용품은 설치 전후와 손동작

`좋아요`, `편해요`, `강력해요`라는 말만으로 끝내지 않고 3~8초 안에 눈으로 확인할 장면을 배치했다.

### 3.3 한 영상에는 한 가지 구매 이유만 남긴다

조회수 상위 단일 상품 영상은 모든 스펙을 소개하지 않았다.

| 상품 | 남긴 한 가지 약속 |
|---|---|
| 응급 가위 | 말도 안 되는 절삭력과 비상 용도 |
| 파워뱅크 | 대용량인데도 빠른 충전 |
| 여행 샤워기 | 여행지 물 문제를 줄이는 휴대성 |
| 립 조합 | 문의가 많았던 발색 재현 |
| 육수 분말 | 한 그릇을 매우 낮은 비용에 완성 |

### 3.4 상품명 공개를 조금 늦추되 제품은 바로 보여준다

제품 실물이나 결과는 0~2초에 보이지만, 정확한 제품명과 설명은 훅 뒤에 배치하는 경우가 많았다. 시청자는 먼저 `무슨 일이 벌어지는지` 보고, 다음에 `무슨 제품인지` 확인한다.

### 3.5 CTA보다 판정이 먼저다

강한 영상은 구매 요청 전에 제작자의 결론을 준다.

```text
이 가격이면 살 만하다
누구에게는 좋지만 누구에게는 과하다
실제 결과가 기대와 달랐다
이 용도 하나 때문에 남길 만하다
```

쇼핑 스티커 CTA는 마지막 2~3초에 짧게 붙이는 것이 자연스럽다.

## 4. 공통 제작 규칙

```text
0~2초: 사건이나 결과
2~5초: 상품 정체 또는 문제
5~15초: 사용 과정
15~25초: 눈으로 보는 증거
25~35초: 솔직한 판정
마지막 2초: 쇼핑 스티커 CTA
```

권장 규칙:

1. 첫 장면에 상품, 결과, 문제 중 최소 하나가 크게 보여야 한다.
2. 첫 문장에는 숫자, 반전, 손해, 질문 중 하나를 넣는다.
3. 2~4초마다 화면 변화 또는 새로운 증거가 필요하다.
4. 장점은 최대 3개, 핵심 구매 이유는 1개만 남긴다.
5. AI 장면만으로 성능을 증명하지 않는다. 핵심 증거는 실제 제품 사진·영상·상품 정보로 구성한다.
6. 광고처럼 `무조건 사세요`라고 끝내지 말고, 맞는 사람과 맞지 않는 사람을 판정한다.
7. CTA는 `왼쪽 아래 쇼핑 스티커에서 제품 정보 확인` 정도로 짧게 끝낸다.

# 템플릿 1. 불가능한 성능 시험형

## 적합 상품

- 공구
- 청소용품
- 전자기기
- 자동차용품
- 내구성이나 성능이 눈으로 보이는 상품

## 핵심 공식

```text
불가능한 질문
→ 바로 시험
→ 예상 밖 결과
→ 실제 사용 목적
→ 한계 또는 실패담
→ 판정
```

## 대본 템플릿

```text
[제품]이 진짜 [불가능해 보이는 대상/상황]까지 된다고요?

이 제품의 핵심은 [검증된 핵심 기능]입니다.
말로만 보면 과장 같아서 직접 [시험 방법]으로 확인해봤습니다.

먼저 [일반적인 조건]에서는 [결과].
이번에는 [더 강한 조건]으로 바꿔보겠습니다.

[결과 장면]
이건 예상보다 [구체적 판정]인데요.

원래 이 제품은 [실제 제조사 용도]에 쓰는 제품입니다.
다만 [안전/성능/사용 조건]은 꼭 확인해야 합니다.

[추천 대상]이라면 제품 정보는 왼쪽 아래에서 확인하세요.
```

## 씬 구분표

| 씬 | 시간 | 내레이션 | 화면 | 통과 기준 |
|---:|---:|---|---|---|
| S01 | 0~2초 | `[제품]이 [극한 행동]까지 된다고요?` | 가장 강한 결과를 먼저 0.5초 보여주고 제품 클로즈업 | 결과가 바로 이해됨 |
| S02 | 2~5초 | `핵심은 [기능]입니다` | 제품명·형태·가격 또는 규격 | 실제 제품과 정확히 일치 |
| S03 | 5~10초 | `일반 조건부터 해보겠습니다` | 기본 시험 | 비교 기준이 보임 |

# 템플릿 3. 문제 괴물 → 해결템형

## 적합 상품

- 여행용품
- 정리·수납용품
- 청소용품
- 생활 불편 개선 제품
- 설치 과정이 간단한 상품

## 핵심 공식

```text
불쾌한 문제 장면
→ 시청자의 경험을 구체화
→ 해결템 등장
→ 설치 1~2단계
→ 오염/수압/정리 전후 증거
→ 관리와 단점
→ 추천 대상
```

## 대본 템플릿

```text
[장소/상황]에서 [불쾌한 문제] 겪어보셨죠?
[문제를 보여주는 장면]을 볼 때마다 진짜 난감합니다.

이럴 때 쓰는 게 [제품명/제품 종류]입니다.
[크기/휴대성]이라 [보관 장소]에 넣기 좋고,
[설치 행동]만 하면 바로 사용할 수 있습니다.

실제로 [검증 방법]으로 확인해보니
[전후 차이]가 보였습니다.

다만 [교체 주기/호환/세척/가격]은 확인해야 합니다.
[구체적인 상황]이 잦은 분이라면 꽤 실용적입니다.

호환 규격은 쇼핑 스티커에서 먼저 확인하세요.
```

## 씬 구분표

| 씬 | 시간 | 내레이션 | 화면 | 통과 기준 |
|---:|---:|---|---|---|
| S01 | 0~2초 | `[상황]의 [문제], 겪어봤죠?` | 가장 불쾌한 문제 클로즈업 | 내 문제처럼 느껴짐 |
| S02 | 2~6초 | `매번 [손실/불편]이 생깁니다` | 실패나 불편을 2개 연속 | 문제를 과장하지 않음 |
| S03 | 6~10초 | `이럴 때 [제품]` | 제품 등장과 크기 비교 | 상품이 선명하게 보임 |
| S04 | 10~16초 | `[행동]만 하면 끝` | 설치·사용 1~2단계 | 초보자도 따라 할 수 있음 |
| S05 | 16~24초 | `직접 확인해보니` | 전후 비교, 필터, 오염, 정리 결과 | 실제 증거 사용 |
| S06 | 24~31초 | `다만 [한계]` | 관리·호환·교체 장면 | 광고보다 리뷰처럼 보임 |
| S07 | 31~35초 | `[상황]이 잦다면 추천` | 제품 + 쇼핑 스티커 여백 | 타깃이 구체적임 |

## 추천 훅 변형

- `[상황]에서 이것 때문에 돈을 두 번 썼습니다.`
- `매번 [행동]하는 분이라면 이 장면부터 보세요.`
- `가장 더러운 결과를 먼저 보여드리겠습니다.`
- `[여행/주방/욕실]에서 이거 없으면 다시 돌아가게 됩니다.`

# 템플릿 4. 문의 폭주·전문가 조합형

## 적합 상품

- 화장품
- 패션
- 식품 조합
- 촬영·업무 장비
- 여러 제품을 함께 써야 결과가 좋아지는 상품

## 핵심 공식

```text
완성 결과 선공개
→ 사람들이 물어본 질문
→ 제품 1~2개 공개
→ 조합 순서
→ 오래 쓰는 이유
→ 누구에게 맞는지
→ 구매 링크 CTA
```

## 대본 템플릿

```text
이 [완성 결과]를 올렸더니 `[무슨 제품이에요?]`라는 질문이 정말 많았습니다.

제가 사용한 건 [제품 A]와 [제품 B]입니다.
먼저 [A 사용법], 그다음 [B 사용법]으로 마무리합니다.

[A]는 [검증된 역할], [B]는 [검증된 역할]을 해서
둘을 같이 쓰면 [눈으로 보이는 결과]가 나옵니다.

제가 이 조합을 계속 쓰는 이유는 [지속력/편의/결과] 때문입니다.
다만 [피부 타입/취향/호환 조건]에는 다르게 느껴질 수 있습니다.

제품 순서대로 쇼핑 스티커에 정리해두겠습니다.
```

## 씬 구분표

| 씬 | 시간 | 내레이션 | 화면 | 통과 기준 |
|---:|---:|---|---|---|
| S01 | 0~2초 | `문의 많았던 결과가 이겁니다` | 완성 얼굴/착장/요리/셋업 | 결과가 가장 예쁜 컷 |
| S02 | 2~6초 | `무슨 제품인지 질문이 많았습니다` | 댓글·문의 화면 또는 재현 그래픽 | 실제 문의가 없으면 허위 연출 금지 |
| S03 | 6~10초 | `[A]와 [B]를 씁니다` | 제품 2개와 이름 | 동일 제품 식별 가능 |
| S04 | 10~17초 | `먼저 A, 다음 B` | 순서대로 시연 | 사용 순서가 명확함 |
| S05 | 17~24초 | `같이 쓰면 [결과]` | 전후 결과 클로즈업 | AI가 아닌 실제 결과 우선 |
| S06 | 24~29초 | `[조건]에는 다를 수 있음` | 추천 대상·주의점 | 전문가 판단이 남음 |
| S07 | 29~32초 | `순서대로 태그했습니다` | 제품 정렬 + 스티커 여백 | 태그 순서와 영상 순서 일치 |

## 사회적 증거가 없을 때의 안전한 변형

실제 문의나 고객 사용 근거가 없으면 `문의 폭주`, `전문가들이 다 쓴다`라고 만들지 않는다.

대신 아래처럼 바꾼다.

```text
이 결과를 만들기 위해 두 가지 조합을 비교해봤습니다.
세 가지 순서로 사용해본 결과, 이 순서가 가장 자연스러웠습니다.
```

# 템플릿 5. BEST 3·5 연속 발견형

## 적합 상품

- 균일가 매장 상품
- 신상품 모음
- 자취·여행·주방 추천템
- 한 판매자나 브랜드의 여러 상품
- 저장을 유도할 수 있는 체크리스트형 콘텐츠

## 핵심 공식

```text
숫자 약속
→ 상품 1: 문제+동작+결과
→ 상품 2: 문제+동작+결과
→ 상품 3: 문제+동작+결과
→ 1순위 선택
→ 저장·쇼핑 CTA
```

## 대본 템플릿

```text
[가격/상황]에서 건진 [숫자]가지, 바로 보여드릴게요.

첫 번째, [상품 1].
[불편]할 때 [동작]하면 [결과]가 됩니다.

두 번째, [상품 2].
[기존 방식] 대신 [간단한 동작]으로 끝납니다.

세 번째, [상품 3].
[작은 특징] 때문에 [구체적인 상황]에서 특히 편합니다.

제가 하나만 고르면 [상품 번호].
이유는 [반복 사용 가능한 핵심 장점]입니다.

필요한 제품은 등장 순서대로 태그해두겠습니다. 나중에 보려면 저장하세요.
```

## 3개형 씬 구분표

| 씬 | 시간 | 내레이션 | 화면 | 통과 기준 |
|---:|---:|---|---|---|
| S01 | 0~2초 | `[상황] 꿀템 3가지` | 3개 결과를 0.5초씩 몽타주 | 숫자 약속이 명확함 |
| S02 | 2~8초 | `첫 번째 [상품]` | 문제 → 손동작 → 결과 | 한 장점만 설명 |
| S03 | 8~14초 | `두 번째 [상품]` | 문제 → 손동작 → 결과 | 이전 상품과 다른 문제 해결 |
| S04 | 14~20초 | `세 번째 [상품]` | 문제 → 손동작 → 결과 | 실제 생활 상황이 보임 |
| S05 | 20~25초 | `하나만 고르면 [번호]` | 1순위 제품 재등장 | 제작자 판단이 구체적임 |
| S06 | 25~28초 | `등장 순서대로 태그했습니다` | 3개 제품 + 스티커 여백 | 태그 순서 일치 |

## 5개형 운영 규칙

- 45~60초로 제작한다.
- 제품 하나당 7~9초를 넘기지 않는다.
- 상품명보다 `무슨 불편을 해결하는지`를 먼저 말한다.
- 모든 상품을 똑같이 칭찬하지 말고 마지막에 1순위를 고른다.
- 서로 다른 판매자의 무관한 상품을 과도하게 태그하지 않는다.
