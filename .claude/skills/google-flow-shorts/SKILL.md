# Google Flow 쇼핑 숏츠 제작 스킬

## 목적

UGC 대본 또는 상품 정보 → **Google Flow 제작 완성 패키지** 출력.  
Google Flow의 AI 영상 생성 특성에 맞춰 프롬프트·스타일·자막·BGM을 최적화한다.

---

## STEP 0 — 입력 수집

```
📦 상품명:
🔗 상품 URL:
🖼️  이미지 URL (상품 사진):
🗂️  카테고리:
    1) 과일별  2) 뷰티  3) 육아  4) 일상생활
    5) 욕실용품  6) 주방용품  7) IT·전자기기  8) 건강·다이어트
🎬  이미 작성된 UGC 대본 있음? [있음 / 없음 → 자동 생성]
🎨  영상 스타일: [UGC 실사 / 모션그래픽 / 스튜디오 촬영 느낌 / 애니메이션]
📐  출력 형식: [9:16 세로 / 16:9 가로 / 1:1 정방형]
⏱️  영상 길이: [15초 / 30초 / 60초]
```

---

## STEP 1 — Google Flow 씬 구성 (카테고리별)

Google Flow는 씬(Scene) 단위로 클립을 조합하므로 씬별로 세분화한다.

### 씬 구성 원칙

- **15초 영상**: 5~6개 씬 (씬당 평균 2.5~3s)
- **30초 영상**: 8~10개 씬 (씬당 평균 3~3.5s)
- **60초 영상**: 15~18개 씬 (씬당 평균 3.5~4s)

### 카테고리별 씬 스타일 가이드

**과일별**
```
스타일: Bright & Fresh / 자연 채광 실사
색보정: 채도 +15, 밝기 +10, 따뜻한 색조
트랜지션: 부드러운 페이드 or 자연스러운 컷
권장 씬: 탑뷰 과일 배열 → 클로즈업 → 손으로 집는 장면 → 신선함 강조
```

**뷰티**
```
스타일: Glamour / 소프트 포커스 실사
색보정: 핑크·베이지 톤업, 하이라이트 강조
트랜지션: 슬로우 페이드, 글리터 효과
권장 씬: 제품 언박싱 → 사용 클로즈업 → Before/After → 표정 반응
```

**육아**
```
스타일: Warm & Cozy / 자연광 실사
색보정: 파스텔 필터, 따뜻한 노란 톤
트랜지션: 부드러운 슬라이드
권장 씬: 아이와 함께하는 장면 → 상품 사용 → 아이 반응 → 부모 미소
```

**일상생활**
```
스타일: Clean & Simple / 라이프스타일 실사
색보정: 뉴트럴·화이트 기반
트랜지션: 빠른 컷, 스피드 램프
권장 씬: 문제 상황 → 상품 등장 → 사용 시연 → 해결된 모습
```

**욕실용품**
```
스타일: Fresh & Clean / 욕실 배경 실사
색보정: 쿨 민트·화이트 필터
트랜지션: 워터 리플 효과 or 심플 컷
권장 씬: 욕실 배경 → 제품 소개 → 사용 장면 → 깔끔한 결과
```

**주방용품**
```
스타일: Warm Kitchen / 요리 영상 스타일
색보정: 따뜻한 우드·크림 톤, 식욕 자극 색감
트랜지션: 빠른 컷 (요리 프로그램 스타일)
권장 씬: 재료 준비 → 제품 사용 클로즈업 → 요리 완성 → 먹는 장면
```

**IT·전자기기**
```
스타일: Dark Tech / 미니멀리즘
색보정: 다크모드 배경, 청록·보라 네온 포인트
트랜지션: 슬라이드·모프 전환
권장 씬: 제품 언박싱 → 스펙 텍스트 오버레이 → 성능 시연 → 화면 앱 클로즈업
```

**건강·다이어트**
```
스타일: Active & Energetic / 야외·헬스장 실사
색보정: 생동감 있는 그린·화이트, 대비 높이기
트랜지션: 에너지 팝 컷, 모션 블러
권장 씬: Before 모습 → 제품 사용 장면 → 운동/식단 장면 → After 변화
```

## STEP 2 — Google Flow 입력 패키지 완성 출력

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🎬 Google Flow 제작 패키지
상품: [상품명] | 카테고리: [카테고리] | 길이: [초]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【프로젝트 제목】
"[상품명] UGC 숏츠 v1"

【씬별 구성표】
┌────┬────────┬────────────────────────────┬───────────────┐
│ 씬 │ 시간   │ 화면 묘사                   │ 비주얼 프롬프트│
├────┼────────┼────────────────────────────┼───────────────┤
│ S1 │ 0~2s   │ [묘사]                     │ [Flow 프롬프트]│
│ S2 │ 2~5s   │ [묘사]                     │ [Flow 프롬프트]│
│ S3 │ 5~9s   │ [묘사]                     │ [Flow 프롬프트]│
│ S4 │ 9~13s  │ [묘사]                     │ [Flow 프롬프트]│
│ S5 │ 13~15s │ [묘사]                     │ [Flow 프롬프트]│
└────┴────────┴────────────────────────────┴───────────────┘

【스타일 설정】
- 비디오 스타일: [카테고리별 스타일]
- 색보정 필터: [설정값]
- 트랜지션: [유형]
- 화면비: [9:16]
- 해상도: 1080×1920

【자막 (Google Flow 자막 입력용)】
[씬 1] 0.0s~1.8s
텍스트: "..."
폰트: 굵게 / 크기 40 / 위치 하단
색상: 흰색 + 검정 테두리 2px

[씬 2] 2.0s~4.5s
텍스트: "..."
폰트: 일반 / 크기 32 / 위치 중앙
색상: 흰색

[씬 3] 5.0s~8.5s
텍스트: "..."
폰트: 굵게 / 크기 38 / 위치 하단
강조 색상: 노랑 (#FFE000)

[씬 4] 9.0s~12.5s
텍스트: "..."
폰트: 일반 / 크기 32
색상: 흰색

[씬 5 - CTA] 13.0s~15.0s
텍스트: "..."
폰트: 굵게 / 크기 44 / 위치 중앙
색상: 포인트 색 (카테고리별)

【BGM 설정】
장르: [카테고리별 추천 장르]
분위기: [키워드]
BPM: [범위]
볼륨: 오프닝 30% → 전개 20% → 엔딩 30%

【음량 레벨 전체표】
┌────────────────┬──────────┬───────┬────────┬──────────┐
│ 트랙           │ 구간     │ dB    │ %      │ 비고     │
├────────────────┼──────────┼───────┼────────┼──────────┤
│ BGM            │ 오프닝   │ -18dB │ 30%    │ 에너지↑  │
│ BGM            │ 전개     │ -24dB │ 20%    │ VO 뒤로  │
│ BGM            │ 엔딩     │ -18dB │ 30%    │ 임팩트↑  │
│ 보이스오버(VO) │ 전구간   │ -6dB  │ 85%    │ 명확하게 │
│ SFX 전환효과   │ 씬 전환  │ -12dB │ 50%    │ 0.2s     │
│ SFX 강조음     │ 결과공개 │ -9dB  │ 60%    │ 임팩트   │
└────────────────┴──────────┴───────┴────────┴──────────┘

【CTA & 게시 정보】
CTA 텍스트: "..."
링크 위치: 영상 하단 or 프로필
캡션 (게시글용):
"..."
해시태그: #... #... #... #...

【Google Flow AI 생성 프롬프트 (통합)】
"Create a [초]s vertical video (9:16) for [상품명].
Style: [스타일].
Scene breakdown:
S1 (0-2s): [영문 씬 묘사]
S2 (2-5s): [영문 씬 묘사]
...
Color grading: [영문 색보정]
Transitions: [영문 트랜지션]
Music: [영문 BGM]
Subtitles: included, Korean, bold, white with black outline."

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## STEP 3 — 플랫폼별 최적화 체크리스트

### 인스타그램 릴스
- [ ] 9:16 세로 확인
- [ ] 첫 0.5s 내 움직임 시작
- [ ] 자막 포함 (무음 시청자 대응)
- [ ] 최대 90초 이하
- [ ] 커버 이미지 선택 (썸네일)

### 유튜브 쇼츠
- [ ] 9:16, 60초 이하
- [ ] 제목에 검색 키워드 포함
- [ ] 첫 화면 = 썸네일급 비주얼

### 틱톡
- [ ] 0~1s 후크 강도 확인
- [ ] 텍스트 오버레이 + 빠른 말 속도
- [ ] 트렌드 사운드 대응 준비
