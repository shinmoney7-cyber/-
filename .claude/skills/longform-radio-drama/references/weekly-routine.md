# Phase 9. 주간·월간 운영 루틴

### 주간 루틴 (반드시 고정)

```
월요일: 지난 주 영상 성과 분석
        → 조회수·시청률·CTR 확인
        → 상위 20% 영상 패턴 기록
        → 다음 사연 유형 결정

화요일: 새 사연 대본 작성 (Phase 1~2)
        → Vrew TTS 생성 (Phase 3)
        → Higgsfield 이미지 생성 (Phase 4)

수요일: CapCut 편집 (Phase 7)
        → 썸네일 완성
        → 화·목 업로드 예약 설정

목요일: SEO 패키지 작성 (Phase 5)
        → 설명란·태그 입력
        → 커뮤니티 게시글 예고

금요일: 댓글 전수 답글
        → 구독자 사연 선별 (다음 주 소재)
        → 수익 트래킹 기록

토요일: 숏폼 하이라이트 편집 (3분)
        → 하루틱·하루꿀템 업로드

일요일: 다음 주 사연 기획 3편 아웃라인
```

### 월간 루틴

```
매월 1일:  수익 정산 확인 (애드센스·멤버십·슈퍼챗)
매월 5일:  다음 달 시리즈 기획 (12~15편 주제 목록)
매월 15일: 채널 성장 지표 리뷰 (구독·시청시간·수익)
매월 말:   다음 달 업로드 스케줄 캘린더 완성
분기별:    사연집 원고 정리 → 전자책 출간 검토
```
