### 8-1. 유튜브 파트너 프로그램 (YPP) 가입 조건

```
구독자:   1,000명 이상
시청시간: 최근 12개월 4,000시간 이상
           OR 쇼츠 조회수 1,000만회/90일
정책:     커뮤니티 가이드라인 위반 없음
필수:     애드센스 계정 연결 + 2단계 인증

⚠️ AI 생성 콘텐츠 주의:
• 매 편마다 스토리 소재 완전히 다르게
• 삽화 매번 새로 생성 (재사용 최소화)
• 나레이션에 사람 감정·편집 다양화
→ "반복적 대량 생성 콘텐츠" 정책 위반 방지
```

### 8-2. 채널 성장 단계별 타임라인

#### 🟡 1단계 — 채널 셋업 (0~2주차)

```
[해야 할 일]
□ 유튜브 채널 개설 + 채널아트/프로필 세팅
□ 채널 소개 동영상 제작 (1~2분)
□ 시리즈 기획 (첫 10편 주제 목록 확정)
□ Vrew 설치 + 음성 테스트
□ Higgsfield 계정 + 크레딧 준비
□ CapCut 설치 + BGM 라이브러리 확보
□ 첫 3편 대본 작성 완료
□ SNS 계정 개설 (인스타·카카오·네이버 블로그)
□ 업로드 스케줄 확정

[목표]
• 첫 편 업로드 전 3편 완성 보유 (안전망)
• 채널 정체성 완성 (썸네일 스타일 통일)
```

#### 🟠 2단계 — 채널 성장 (1~3개월차 / 영상 1~20편)

```
[업로드 목표]
• 주 2~3편 꾸준히
• 화·목·일 오후 9시 권장
  (30~60대 타겟 최고 시청 시간대)

[해야 할 일]
□ 영상 20편 누적 업로드
□ 썸네일/제목 A·B 테스트 (2편씩 비교)
□ 댓글 모두 직접 답글
□ 커뮤니티 탭 활성화 (사연 예고·투표)
□ 시청 지속률 40% 미달 편 → HOOK 분석 개선

[수익 현황]
• YPP 미달 → 수익 0원
• 준비: 애드센스 계정 미리 생성
• 목표 달성 예상: 3개월차 말~6개월차 초

[핵심 KPI]
• 15초 이탈률: 30% 이하 (HOOK 품질)
• 평균 시청 지속률: 40% 이상
• 노출 클릭률(CTR): 4~8%
```

#### 🟢 3단계 — YPP 달성 & 첫 수익 (3~6개월차 / 구독 1,000명)

```

□ 숏폼 하루틱/릴스 채널 병행 시작
```

### 8-3. 광고 수익 계산 기준 (RPM)

```
[한국어 채널 RPM 평균 — 사연/드라마 장르]
• RPM: ₩800~2,000/1,000회 조회
• 60분 롱폼 → 시청 지속률 40% 가정 → 실질 CPM 높음

[실제 수익 계산 예시]
월 업로드 12편 × 편당 평균 조회 5,000회
= 월 60,000회 조회
× RPM ₩1,200 / 1,000
= 월 광고 수익 약 72,000원

→ 조회수 10만회/월 기준: 약 12~20만원
→ 조회수 100만회/월 기준: 약 80~200만원

[일본어 채널 RPM — 시니어 대상]
• RPM: ¥500~1,500/1,000회 (한국보다 단가 높음)
• 소규모 구독에도 광고 단가 유리

[영어 채널 RPM]
• RPM: $2~6/1,000회 (최고 단가)
• 글로벌 시청자 타겟 → 장기 성장 잠재력 최고
```
