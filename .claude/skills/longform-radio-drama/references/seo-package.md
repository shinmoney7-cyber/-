# Phase 5. SEO 패키지

### 제목 5개 공식

| 공식 | 형태 | 예시 |
|------|------|------|
| A — 숫자+기간 | `[N년] 동안 몰랐습니다` | "23년 동안 몰랐습니다 / 남편의 이중생활" |
| B — 반전 암시 | `[사실]. 그런데 [충격]` | "그 여자는 제 절친이었습니다. 그런데…" |
| C — 감정 직격 | `[행동]했습니다 / [상황]` | "남편 핸드폰을 봤습니다 / 시누이 문자 실화" |
| D — 관계 명시 | `[관계] [행동] [결과]` | "며느리가 꺼낸 서류 한 장, 시어머니가 주저앉았다" |
| E — 질문형 | `[상황], 여러분이라면?` | "남편이 용서를 빌었습니다. 여러분이라면?" |

**제목 규칙**
```
✅ 40~60자 / 결말 숨기기 / 구체적 숫자 포함
✅ 행동 묘사로 끝내기 (주저앉았다, 결심했다)
❌ 추상적 표현 / 결말 스포일러
```

### 태그 30개 생성 공식

```
필수 공통 10개:
#사연 #라디오드라마 #실화사연 #정희의밤라디오
#롱폼 #60분 #눈물사연 #공감사연 #감동사연 #한국사연

유형별 10개 (예: 외도):
#외도 #불륜 #남편외도 #배신 #이혼사연
#부부사연 #결혼생활 #충격사연 #반전사연 #사이다결말

SEO 검색 10개:
#사연모음 #실화 #라디오 #드라마 #오디오드라마
#유튜브사연 #[클라이맥스 키워드] #[관계 유형] #[감정] #[결말키워드]
```
