# 쇼핑 숏츠 수익 최대화 스킬 (Higgsfield)

기존 sync-shopshorts-higgs 6단계를 그대로 쓰되, 매출에 직접 영향 주는 단계를 앞뒤로 추가한 버전.
참고 파일은 이 스킬 폴더의 `references/`에 있다: `references/persona-mapping.md`, `references/preset-mapping.md`, `references/script-templates.md`, `references/quality-checklist.md` (sync-shopshorts-higgs와 같은 내용).
"원본 유지"라고 적힌 단계의 규칙은 이 문서에 모두 옮겨 적었으므로 다른 스킬을 열 필요는 없다.

## 사용 도구 + 설치
- Higgsfield MCP: `show_marketing_studio_v2`, `show_marketing_studio_generations`, `generate_video`, `balance`, `virality_predictor`, `tiktok_music_trending`. deferred면 ToolSearch로 로드, 아예 없으면 claude.ai 설정 > 커넥터에서 Higgsfield 연결 안내.
- 검수용: `curl`, `ffmpeg` — 맥 `brew install ffmpeg` / 리눅스 `sudo apt-get install -y ffmpeg curl`.

## 진행 체크리스트
- [ ] 0. 수익성 필터 — 점수표, 3점↓ 패스 권고
- [ ] 1. 상품 등록 — 크롤링 요약
- [ ] 2. 사실 검증 + 페인포인트 + 페르소나 — 확인받기
- [ ] 3. 개수 + 템플릿 × 프리셋 — 예상 크레딧 표시
- [ ] 4·5. 대본·씬 구조도 + 제목·커버 순위 — ⛔ 승인
- [ ] 6. 생성 — ⛔ 총 크레딧·잔액 승인 후 제출
- [ ] 7. 검수 + 바이럴 예측 — 탈락이면 "돌아갈 단계"대로
- [ ] 8. 업로드 패키지 — 대가성 문구 포함 확인
- [ ] 9. 성과 체크 — 24~48시간 후

## 공통 규칙
- 대화는 **반말**, 짧게. 각 단계 시작 때 "지금 N단계 → 다음 M단계" 한 줄만.
- 사용자 손이 필요한 일은 `👉 할 일:`로 따로 표시. 나머지는 알아서 끝낸다.
- 한국인 전용: 등장인물 `Korean man/woman in their Ns`, 대사·자막·음성 전부 한국어.
- 편집 원칙: 한 장면 안에서 자막 카드가 넘어가지 않게(장면 바뀔 때만 자막 교체), 사진 슬라이드 대신 **제품을 실제로 쓰는 장면** 위주.
- 지어내기 금지: 상품 페이지·실제 리뷰에 없는 효능, 가짜 후기("제가 써보니"), 근거 없는 숫자 금지.

## 입력
- 상품 URL 1개 이상 (필수) — 쿠팡 / 올리브영 / 네이버 / 다이소
- 타깃·강조점·예산(크레딧) (선택)

## 0단계. 소재 수익성 필터 (신규)
여러 개 들어오면 점수로 순위를 매겨 위에서부터 만든다. 1개면 점수만 보여주고 진행.

| 항목 | 기준 | 점수 |
|---|---|---|
| 가격대 | 1~5만원 = 충동구매 구간(최고) / 5~15만원 중간 / 그 외 낮음 | 0~3 |
| 문제 해결이 눈에 보이나 | 사용 전/후가 영상으로 바로 보이면 높음 | 0~3 |
| 리뷰 수·평점 | 리뷰 많고 4.5↑ = 신뢰 장면 만들기 쉬움 | 0~2 |
| 반복 구매·소모품 | 재구매형이면 +1 | 0~1 |
| 광고 리스크 | 건강기능식품·의료기기·다이어트 효능 주장 필요하면 −2 | −2~0 |

7점↑ 바로 제작 / 4~6점 1개만 테스트 / 3점↓ 패스 권고.

## 1단계. 상품 등록
`show_marketing_studio_v2`(또는 사용 가능한 marketing studio 도구)로 상품 크롤링 → 상품명·가격·이미지·핵심 스펙 한국어 요약. Higgsfield 도구가 deferred면 ToolSearch로 먼저 로드.

## 2단계. 사실 검증 + 리뷰 페인포인트 + 페르소나 (강화)
- A. 검증된 사실 (페이지에 명시된 스펙·가격·구성) / B. 금지할 주장 (직접 사용 경험이 없으므로 후기형 멘트 금지, 페이지에 없는 성능 주장 금지)
- **C. 리뷰 페인포인트 TOP3**: 상품 페이지·리뷰에서 "사기 전 불편했던 점" 3개 추출. 훅과 문제 제기 장면은 반드시 여기서 가져온다.
- **D. 구매 망설임 TOP3**: 비싸다 / 진짜 되나 / 나한테 맞나 같은 반박 포인트. 4단계 '반박 대응 멘트'에 쓴다.
- 페르소나: `references/persona-mapping.md`로 성별·나이대 결정 → 근거 한 줄과 함께 제시.

## 3단계. 개수 + 템플릿 × 프리셋 (수익 기준)
- 템플릿은 `references/script-templates.md` §5 선택표로 1·2순위, 프리셋은 `references/preset-mapping.md` 매핑표로 템플릿마다 2~3개.
- 크레딧은 `get_cost:true`로 사전 확인 후 개수별 예상 차감액 병기.
- 기본 추천은 **2개 A/B 훅 테스트**(같은 페르소나, 훅만 다르게). 훅 효과를 데이터로 확인하는 게 매출 상승의 지름길이라서.
- 3개: 문제형 / 가성비형 / 비교·실험형 1개씩. 4개: 페르소나 2 × 템플릿 2.

## 4단계. 대본 + 씬 구조도 ⛔ 승인 게이트 (강화)
25초 기본 6구간으로 짠다: 후킹(0~2초) → 문제공감(2~5초) → 제품등장=해결(5~12초) → 베네핏 실증(12~18초) → 신뢰요소(18~22초) → CTA(22~25초).

씬 구조도 표 (원본 형식 + 이탈 열 추가):

| 씬 | 시간 | 화면 | 대사/내레이션 | 자막(짧고 굵게) | BGM | 이탈 위험·대응 | 생성 방식 |
|---|---|---|---|---|---|---|---|

- **이탈 위험 열**: 보통 2~3초(훅 직후)와 제품 설명 들어가는 순간이 제일 위험. 그 칸에 "전후 대비 컷 / 숫자 자막 / 소리 효과" 등 대응을 적는다.
- **멘트 가이드 5종**을 표 아래 따로 정리: ① 오프닝 ② 장점 설명 ③ 반박 대응(2단계 D에서) ④ 마감·한정 멘트(실제 할인·재고 정보 있을 때만, 없으면 "지금 가격 확인"류로) ⑤ 링크 유도. 톤은 광고 말고 **친구가 추천하는 말투**.
- 핵심 성능 증명은 실제 상품 이미지/정보 기반. AI 장면으로 성능을 증명하지 않는다.

**⛔ 표 출력 후 멈추고 승인 대기. 승인 전 생성 도구 호출 금지.** 여러 개면 세트 전체 1회 승인.

## 5단계. 제목·커버 문구 순위 (신규, 4단계 표와 같이 보여줌)
제목 5안 + 커버(첫 프레임) 문구 5안을 만들고 표로 채점:

| 안 | 문구 | 클릭유발 | 신뢰도 | 정보성 | 호기심 | 제품노출 | 합계 |
|---|---|---|---|---|---|---|---|

각 1~5점. 합계 1위를 기본으로 쓰고, A/B 2개 제작이면 1·2위를 각 영상에 배정. 과장·낚시("무조건", "100%")는 신뢰도 1점 처리.

## 6단계. 생성 실행
- **크레딧 승인 게이트**: `get_cost:true`로 영상별 차감액, `balance`로 잔액 확인 → "총 N크레딧 / 잔액 M" 제시 후 멈춘다. 금액 승인이 따로 나오기 전에는 생성 도구를 호출하지 않는다 (4단계 대본 승인은 금액 승인이 아니다).
- `generate_video` (model `marketing_studio_video`). `url/type/mode`는 무시되므로 상품 이미지는 `medias: [{value, role:'image'}]`로, 프리셋 스타일은 프롬프트 안에.
- 프롬프트 필수: `Korean <gender> in their <age>s`, `All dialogue spoken in Korean` + 대사 원문, 씬 묘사, `aspect_ratio: '9:16'`, 실사용 장면 묘사.
- 15초 단일 연출은 1회 생성 / 30초 이상은 인물 씬만 생성하고 제품 단독 씬은 실제 이미지로 CapCut 조립 안내.
- ⚠️ 500 오류 처리 절차 (접수됐을 수 있어 바로 재시도하면 크레딧 이중 차감):
  1. 재시도하지 않는다.
  2. `show_marketing_studio_generations`로 방금 작업이 목록에 있는지 확인한다.
  3. 있으면 그 job을 기다리고, 없을 때만 1회 재시도. 다시 실패하면 멈추고 보고.

## 7단계. 검수 + 바이럴 예측 (강화)
1. 프레임 검수: 다운로드 → 중간 프레임 추출 → Read로 확인 → `references/quality-checklist.md` 적용.
   ```
   curl -sL -o v.mp4 <rawUrl> && ffmpeg -y -loglevel error -i v.mp4 -ss 8 -frames:v 1 frame.jpg
   ```
   돌아갈 단계: 인물이 외국인이거나 성별·나이대가 다름 → 6단계(프롬프트 보강 후 재생성) / 페르소나가 상품과 안 맞음 → 2단계 / 깨진 한글을 크롭·스티커로 못 가림 → 6단계.
2. **바이럴 예측**: 통과 영상을 `virality_predictor`에 넣어 (크레딧이 든다고 나오면 6단계와 같이 금액 승인 먼저) 훅 강도·이탈 위험 구간을 받는다. 약한 구간은 "앞 1초 잘라내기 / 자막 교체 / 컷 순서 변경" 중 크레딧 안 드는 수정부터 제안.
3. A/B 세트면 예측 점수가 높은 쪽을 먼저 올리도록 순서 추천.

### 검사 → 고치기 → 반복
- 기준: `references/quality-checklist.md` + 5단계 채점표 + 바이럴 예측 결과.
- 미통과 항목은 위 "돌아갈 단계"대로 고치고 다시 검사한다. 전부 통과해야 8단계로 간다. 재생성은 매번 6단계 크레딧 승인을 다시 받는다.
- 기준에 없는 이유로 탈락시켰다면, 작업 끝에 새 규칙 1개를 제안하고 사용자 승인을 받는다.

## 8단계. 업로드 패키지 (신규)
영상마다 복붙용으로 한 번에 출력:
- 제목 (5단계 1위)
- 설명란 첫 줄 = 구매 링크 유도 문장 + 링크 자리 `[링크]`
- **대가성 문구 필수**: 쿠팡 파트너스면 "이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다." 그 외 제휴도 "제휴 링크 포함" 표기. 빠지면 표시광고법 위반 위험.
- 고정 댓글 문구 (링크 + 한 줄 혜택)
- 해시태그 3~5개 (상품 카테고리 + 문제 키워드)
- 플랫폼별 변형이 필요하면 쇼츠/릴스/틱톡 각 1줄씩만 바꿔서.
- 딥링크 생성은 coupang-partners-autolink 스킬로 넘긴다.

👉 할 일: 업로드 + 링크 붙이기.

## 9단계. 성과 체크 + 안 터졌을 때 플랜 (신규)
업로드 후 24~48시간 숫자(조회수, 시청 지속률, 링크 클릭, 매출)를 받으면 아래 표로 진단하고 바로 다음 행동 1개를 정해준다.

| 증상 | 원인 추정 | 가장 빠른 대응 | 대신 올릴 것 |
|---|---|---|---|
| 조회수 자체가 안 나옴 | 훅 약함 / 노출 저조 | 같은 영상에 훅 첫 1~2초만 바꿔 재업로드 | 5단계 2위 제목·커버로 B버전 |
| 조회는 나오는데 초반 이탈 | 2~3초 구간 약함 | 문제 장면을 맨 앞으로 당겨 재편집 | 비교·실험형 템플릿 |
| 끝까지 보는데 클릭 없음 | CTA·링크 동선 약함 | 고정댓글·설명 첫 줄 교체 | 가격·혜택 강조 버전 |
| 클릭은 있는데 매출 없음 | 상품 페이지·가격 문제 | 상품 교체 검토(0단계 점수 재계산) | 같은 카테고리 다른 상품 |
| 악플·반박 댓글 | 과장으로 보임 | 근거 있는 답글 고정, 과장 표현 수정 | 리뷰 근거형 버전 |
| 저작권 경고·비공개 처리 | BGM·타 영상 소스 | 문제 소스 제거 후 재업로드, 무료/라이선스 음원으로 교체 | 사전 준비해둔 예비 영상 |

- **미리 준비할 것**: 상품마다 훅만 다른 예비 버전 1개는 항상 만들어 둔다(재업로드용).
- 트렌드는 AI 추측 말고 실제 데이터로: 잘 터진 레퍼런스 영상 분석(리바이럴 메이커 방식)이나 `tiktok_music_trending` 같은 실데이터 도구를 쓴다.

## 완료 보고 형식
결과 영상 + 판정 / 차감 크레딧·잔액 / 업로드 패키지 / 👉 사용자 할 일 / 다음 추천 1개.
