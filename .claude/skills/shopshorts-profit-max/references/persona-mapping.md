# 타깃 페르소나 매핑표 (한국인 전용)

영상 등장인물은 항상 **한국인**. 이 표로 성별·나이대 기본값을 정하고, 상품 페이지 신호로 보정한다.

## 1. 카테고리 → 기본 페르소나

| 상품 카테고리 | 기본 등장인물 | 근거 |
|---|---|---|
| 색조 화장품, 스킨케어(20대向) | 20대 한국인 여성 | 뷰티 숏츠 주 시청층 |
| 안티에이징, 기능성 화장품 | 30~40대 한국인 여성 | 구매력 + 니즈 일치 |
| 주방가전 (밥솥, 에어프라이어 등) | 30~40대 한국인 여성 또는 부부 | 신혼·주부 구매층 |
| 생활가전 (청소기, 공기청정기) | 30~40대 한국인 남성/여성 | 성별 중립, 상품 톤으로 결정 |
| 공구, 자동차용품 | 30~50대 한국인 남성 | 카테고리 주 구매층 |
| 테크 가젯, 충전기, 주변기기 | 20~30대 한국인 남성 | 테크 리뷰 시청층 |
| 유아용품, 육아템 | 20~30대 한국인 부모 (여성 우선) | 육아 콘텐츠 문법 |
| 건강기능식품, 홍삼 | 40~60대 한국인 남성/여성 | 시니어 타깃, 선물 수요 |
| 식품, 간편식 | 20~30대 한국인 (1인 가구 톤) | 자취·가성비 문법 |
| 패션 (여성복) | 20~30대 한국인 여성 | 트라이온 프리셋 적합 |
| 패션 (남성복, 스니커즈) | 20~30대 한국인 남성 | Virtual Try-On Sneakers 등 |
| 여행용품 | 20~40대 한국인 남성/여성 | 여행 브이로그 톤 |
| 정리·수납·청소용품 | 30~40대 한국인 여성 | 살림 콘텐츠 문법 |
| 홈트, 운동기구 | 20~30대 한국인 남성/여성 | 전후 비교 문법 |

## 2. 보정 신호 (상품 페이지에서 확인)

| 신호 | 보정 방향 |
|---|---|
| 상세페이지 모델 이미지의 성별/나이대 | 그대로 따르는 것을 1순위로 검토 |
| 고가 (카테고리 평균 대비 상위) | 나이대 +10세 (구매력 반영) |
| 초저가·가성비 강조 카피 | 20~30대, 자취/신혼 톤 |
| "부모님 선물", "효도" 카피 | 구매자(30~40대)와 사용자(60대+)를 분리 — 등장인물은 구매자 기준, 사용 장면에 시니어 등장 가능 |
| 육아·아이 언급 | 20~30대 부모 |
| 전문가·프로용 카피 | 30~50대, Direct-to-Camera 프리셋 적합 |

## 3. 출력 형식

Phase 2에서 아래 형식으로 사용자에게 제시하고 확인받는다.

```
타깃 페르소나 분석 결과
- 등장인물: 30대 한국인 여성
- 근거: ① 주방가전 카테고리 ② 상세페이지 모델이 30대 여성 ③ 신혼 타깃 카피 ("둘이 먹기 딱 좋은")
- 대안: 30대 부부 (Couple Sharing At Home 프리셋 사용 시)
```

## 4. 생성 프롬프트 규칙

- 영어 프롬프트에 반드시 명시: `a Korean woman in her 30s`, `a Korean man in his 40s` 등
- 대사·음성은 한국어로 지정: `speaking in Korean`, 한국어 대사 원문 전달
- 외국인·무국적 외모가 나오면 재생성 대상으로 판정한다.
