# 최종 검수 체크리스트

생성 완료 후 각 항목을 통과/미통과로 판정해 보고한다.

## 한국인 전용 규칙 (이 스킬 고유)

- [ ] 등장인물이 한국인 외모로 생성되었다 (외국인/무국적 외모면 재생성).
- [ ] 성별·나이대가 Phase 2에서 확정한 페르소나와 일치한다.
- [ ] 음성·대사·자막이 모두 한국어다.

## 조회수 구조

- [ ] 첫 2초에 제품·결과·문제 중 하나가 크게 보인다.
- [ ] 첫 문장에 숫자·반전·질문·손해 중 하나가 있다.
- [ ] 5초 안에 영상의 약속을 이해할 수 있다.
- [ ] 2~4초마다 새로운 정보나 화면 변화가 있다.
- [ ] 핵심 구매 이유가 하나로 압축되어 있다.

## 쇼핑 신뢰

- [ ] 실제 태그 상품과 영상 속 상품이 같다.
- [ ] 가격과 할인은 현재 정보인지 확인했다.
- [ ] 직접 써보지 않았다면 사용 후기처럼 말하지 않는다.
- [ ] 성능 증거를 AI 생성 장면으로 대체하지 않는다.
- [ ] 맞는 사람과 맞지 않는 사람을 함께 제시한다.

## 업로드

- [ ] 대표 상품을 태그 목록 첫 번째에 둔다.
- [ ] 쇼핑 스티커가 자막과 겹치지 않는다.
- [ ] 제휴 수익 또는 협찬 공개 문구를 확인한다.
- [ ] 현실적인 AI 생성 장면은 AI 사용 공개 여부를 확인한다.
- [ ] 음악은 쇼핑 콘텐츠에서 사용 가능한 음원인지 확인한다.
