# 재미(엔터테인먼트) 대본 스타일 체크리스트

번역·재구성한 대본이 "재미있게 읽히는 하이라이트 클립"에 가까운지 점검하는 체크리스트.
뉴스 보도체가 아니라 예능/리액션 콘텐츠 톤을 기준으로 한다.

## 대화 번역 자연스러움

- [ ] 인물의 말투(반말/존댓말, 급함/느긋함, 장난기 등)가 대사에 드러나는가
- [ ] 직역투("~하는 것을 하다" 식 번역체)가 남아있지 않은가
- [ ] 인물이 여러 명이면 화자별 말투가 서로 구분되는가
- [ ] 관용구/농담이 한국 시청자가 바로 웃을 수 있는 표현으로 옮겨졌는가 (의미 왜곡 없이)

## 연출 지시 (클로즈업 · 비교)

- [ ] 감정이 터지는 순간마다 클로즈업 지시가 명시되어 있는가
- [ ] 비교(Before/After, 예상 vs 실제) 넣을 지점이 최소 1곳 이상 표시되어 있는가
- [ ] 효과음 자막·강조 텍스트가 재미 포인트에 배치되어 있는가
- [ ] 컷 템포(빠른 전환 vs 여백)가 장면 성격에 맞게 메모되어 있는가

## 몰입도

- [ ] 첫 3초 안에 "어? 뭐지?" 싶은 궁금증이 생기는가
- [ ] 중간에 늘어지는 구간 없이 재미 포인트가 일정 간격으로 배치되어 있는가
- [ ] 마지막에 다음 영상/시리즈로 이어질 여지(떡밥)가 있는가 (선택)

## 사실 검증 (재미를 위해 왜곡하지 않았는가)

- [ ] 번역 대사가 원문 발언의 핵심 의미를 그대로 유지하는가
- [ ] 편집으로 맥락이 실제와 다르게 보이도록 왜곡되지 않았는가
- [ ] 제목/썸네일 문구가 실제 영상 내용과 부합하는가 (과장된 낚시 아님)
